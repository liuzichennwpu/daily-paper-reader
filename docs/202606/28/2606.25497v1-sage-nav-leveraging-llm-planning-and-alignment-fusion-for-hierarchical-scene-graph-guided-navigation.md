## 摘要
对象目标导航（ObjNav）要求具身智能体仅利用自我中心的视觉观测自主定位指定目标。现有的单一方法难以进行长程推理，且对新颖环境的泛化能力较差。为解决这些限制，我们提出SAGE-Nav，一种新颖的分层框架，将大语言模型（LLM）的推理能力与动态场景图相结合。关键之处在于，它将异步的全局语义规划与高频反应式控制环路解耦。LLM作为全局规划器，将抽象指令分解为一系列语义锚定的航路点。为了将这些规划转化为密集的多模态引导，我们设计了分层场景图编码器（HSGE），利用关系图卷积生成结构感知嵌入，保留语义和空间拓扑。此外，我们开发了目标感知对齐融合网络（GAFN），动态地将实时感知与这些结构先验融合。通过具有显式归纳偏置的自适应门控机制，GAFN确保底层策略的鲁棒视觉-拓扑对齐。在i-THOR和RoboTHOR环境中的广泛评估表明，SAGE-Nav实现了最先进的性能，在导航效率和零样本泛化方面取得了显著提升，同时保持了物理机器人部署所需的低控制延迟。

## Abstract
Object-Goal Navigation (ObjNav) requires embodied agents to autonomously locate specified targets using only egocentric visual observations. Existing monolithic methods struggle with long-horizon reasoning and generalize poorly to novel environments. To address these limitations, we propose SAGE-Nav, a novel hierarchical framework that integrates the reasoning capabilities of Large Language Models (LLMs) with dynamic scene graphs. Crucially, it decouples asynchronous global semantic planning from the high-frequency reactive control loop. The LLM serves as a global planner, decomposing abstract instructions into a sequence of semantically grounded waypoints. To translate these plans into dense multi-modal guidance, we design a Hierarchical Scene Graph Encoder (HSGE) that leverages relational graph convolutions to produce structure-aware embeddings preserving both semantic and spatial topology. Furthermore, we develop the Goal-aware Alignment-Fusion Network (GAFN) to dynamically fuse real-time perception with these structural priors. Using an adaptive gating mechanism with an explicit inductive bias, GAFN ensures robust visual-topological alignment for the low-level policy. Extensive evaluations in the i-THOR and RoboTHOR environments demonstrate that SAGE-Nav achieves state-of-the-art performance, delivering substantial gains in navigation efficiency and zero-shot generalization while maintaining the low control latency required for physical robotic deployment.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- **分层规划与解耦**：LLM作为异步全局规划器，将抽象指令分解为语义锚定的航路点序列；高频反应式控制环路独立运行，仅在有子目标达成或死锁时触发重新规划。
- **结构化知识蒸馏**：LLM的推理结果通过场景图编码器（HSGE）转换为结构化嵌入，再通过对齐融合网络（GAFN）与实时感知动态融合，避免运行时频繁调用LLM。
- **显式归纳偏置**：GAFN中的自适应门控机制根据视觉-拓扑对齐程度调整融合权重，鼓励智能体在接近目标时更依赖结构先验而非原始感知，提供连续的可解释进度信号。

### 关键技术细节
1. **层次化场景图构建**：
   - 形成包含对象节点和抽象区域节点的层次图 \( G = (V, E) \)。
   - 节点属性包括语义类别、3D质心、CLIP视觉嵌入、层级、VLM摘要。
   - 融合策略：基于混合相似度 \( S_{ij} = (1-\alpha)S_{\text{spatial}} + \alpha S_{\text{semantic}} \) 进行增量聚类，平衡空间与语义。
   - 边类型：同层空间连接（距离约束）、跨层层次边（语义包含关系）。

2. **LLM引导的全局规划（H-GP）**：
   - 先提取指令相关子图 \( G_Q \)，过滤无关节点（考虑语义相似度+邻域空间增强）。
   - 将规划视为旅行商路径问题（TSPP），通过层次一致性权重 \( W(v_i,v_j) = \lambda_{\text{sem}} S_{\text{multi-level}} - \lambda_{\text{dist}} D_{\text{geo}} \) 进行贪婪选择。
   - 对未知目标进行假设性推理：根据LLM的上下文共现概率选择最可能的高层区域，创建虚拟节点加入规划。

3. **层次化场景图编码器（HSGE）**：
   - 使用关系图卷积（R-GCN）对每个层次进行结构感知编码，保留残差连接防止过平滑。
   - 用活跃航路点嵌入 \( x_w \) 对节点进行注意力加权注入（\( \tilde{h}_v^{(\ell)} = h_v^{(\ell)} + \alpha_v x_w \)）。
   - 跨层次平均池化后经MLP输出最终航路点嵌入 \( E_w \)。

4. **目标感知对齐融合网络（GAFN）**：
   - 结构注入交叉注意力：视觉特征 \( F_v \) 作为查询，\( E_w \) 作为键值，得到 \( F_a \)。
   - 对齐感知门控融合：计算余弦对齐分数 \( \alpha_t = \cos(F_v, E_w) \)，门控向量 \( \lambda(\alpha_t) = \sigma( \text{MLP}([F_v;F_a;E_w;\alpha_t]) ) \cdot (1 - \eta \sigma(\kappa \alpha_t)) \)。
   - 融合输出 \( F_f = \lambda \odot F_v + (1-\lambda) \odot F_a \)，当对齐度高时减少对原始视觉依赖，转向结构引导。

5. **强化学习优化**：
   - 基于A3C异步框架，策略网络为两层LSTM Actor-Critic。
   - 奖励函数 \( R_{\text{nav}} = 5 \cdot \mathbb{I}_{\text{vis}} + 0.01 \cdot \mathbb{I}_{\text{fwd}} + \max(\lambda \Delta d_t, 0) - 0.01(1-\mathbb{I}_{\text{vis}}) \)。
   - 训练6百万回合，使用Adam优化器，学习率1e-4。
