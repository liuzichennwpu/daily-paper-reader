## 摘要
语义变化检测(SCD)旨在同时定位土地覆盖变化并识别变化前后的语义类别。然而，现有方法存在跨时相对齐不足、多尺度表示弱以及对光照、季节和配准噪声引起的伪变化鲁棒性差等问题。为解决这些问题，我们提出了一种新颖的端到端语义变化检测网络SemDINO，该网络将双分支编码器、多尺度时相交互、语义纯化、变化增强以及解耦的多任务预测集成到一个统一框架中。具体而言，我们构建了一个双分支编码器，通过门控金字塔融合将CNN骨干网络和冻结的DINOv3特征相结合，从而获得丰富的多尺度语义表示。随后，提出了多尺度时相双向变换器交互(M-TBTT)模块，以实现全局跨时相特征对齐和信息交互。为进一步增强真实变化并抑制伪变化，我们协同引入了语义纯化(SCP)、双向变化增强(BiChangeEnhance)和多尺度变化增强(MCE)模块。最后，设计了一个多分支变化检测(CD)预测头，联合输出二值变化掩码、双时相语义图和边缘约束。在公开遥感CD数据集上的大量实验表明，SemDINO相比现有最先进方法取得了优越的性能和泛化能力，尤其是在存在干扰因素的复杂场景中。

## Abstract
Semantic change detection (SCD) aims to simultaneously locate land-cover changes and identify semantic categories before and after transition. However, existing methods suffer from insufficient cross-temporal alignment, weak multi-scale representation, and poor robustness to pseudo-changes caused by illumination, season, and registration noise. To address these issues, we propose a novel end-to-end semantic change detection network named SemDINO, which integrates a dual-branch encoder, multi-scale temporal interaction, semantic purification, change enhancement, and decoupled multi-task prediction into a unified framework. Specifically, we construct a dual-branch encoder that combines a CNN backbone and frozen DINOv3 features via gated pyramid fusion, enabling rich multi-scale semantic representation. Then, a multi-scale temporal bidirectional transformer interaction (M-TBTT) module is proposed to achieve global cross-temporal feature alignment and information interaction. To further enhance genuine changes and suppress pseudo-variations, we introduce semantic purification (SCP), bidirectional change enhancement (BiChangeEnhance), and multi-scale change enhancement (MCE) modules collaboratively. Finally, a multi-branch CD prediction head is designed to jointly output binary change mask, bi-temporal semantic maps, and edge constraint. Extensive experiments on public remote sensing CD datasets demonstrate that SemDINO achieves superior performance and generalization ability against state-of-the-art methods, especially in complex scenarios with interference factors.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 以**跨时相语义对齐**为核心，构建“双分支编码器 + 多尺度双向时序Transformer + 变化增强流水线 + 解耦多任务预测头”的统一框架。
- 利用**冻结的DINOv3**提供稳定语义先验，通过门控金字塔融合注入CNN特征；通过**双向时序交互**消除时序顺序偏差；通过**语义净化与多尺度变化增强**抑制伪变化、增强真实变化。

### 关键技术细节（按流水线顺序）

#### (1) 双分支编码器与金字塔融合（PyFu）
- 双分支：可训练的CNN骨干（ResNet50）+ FPN提取多尺度特征 \(F_{pyramid,t}^i\)；冻结的DINOv3提取语义特征 \(F_{dino,t}^i\)。
- **SepAB**（Separate Adaptation Block）：对DINOv3特征进行瓶颈适配（Conv1×1 → BN → DW-Conv3×3 → BN → Conv1×1）。
- **GatedFusion**：将适配后的DINOv3特征与CNN特征拼接后，经通道注意力（CA）和空间注意力（SA）生成门控信号，加权补偿CNN特征的语义不足。最终输出 \(f_{t,i} = F_{pt,i} + \Delta_{t,i}\)，保留局部细节的同时注入语义先验。

#### (2) 多尺度双向时相Transformer交互（M-TBTT）
- 在四个金字塔级别分别执行**双向跨时相注意力**：
  - Stage1（T1→T2）：\( f'_{1,i} = f_{1,i} + g_{1,i} \cdot A(W_q f_{1,i}, W_k f_{2,i}, W_v f_{2,i}) \)
  - Stage2（T1←T2）：\( f'_{2,i} = f_{2,i} + g_{2,i} \cdot A(W_q f_{2,i}, W_k f_{1,i}, W_v f_{1,i}) \)
- 学习门控 \(g\) 初始化为0，从恒等映射开始，逐步学习跨时相校正，实现对称对齐，消除时序顺序偏差。

#### (3) 变化增强流水线 #FeaCE（针对最深层次特征 \(f'_{1,4}, f'_{2,4}\)）
- **BiChangeEnhance (BCE)**：计算特征差绝对值，结合和分支的门控与残差分支，提取初始变化特征 \(F_{BCE}\)。
- **Semantic Clean Purification (SCP)**：从 \(F_{BCE}\) 估计变化掩码 \(M_{chg}\)，取其反获非变化掩码 \(M_{nchg}\)；用非变化掩码过滤特征，并通过门控跨时相细化，得到“干净”的双时相特征 \(f'_{1,clean}, f'_{2,clean}\)。在非变化区域促进语义一致性，在变化区域保留差异。
- **Multi-scale Change Enhancement (MCE)**：计算干净特征差 \(D_{clean}\)，经三种尺度池化（1×,2×,4×）与门控融合，降低局部分布式噪声方差，最后与 \(F_{BCE}\) 残差连接得到最终增强变化特征 \(F_{#FeaCE}\)。

#### (4) 特征融合与多任务预测头（ChangeFusion & CD-Head）
- **ChangeFusion**：将三个尺度的对齐后的T1特征、T2特征及增强变化特征上采样后拼接，经1×1卷积和通道注意力加权融合，得到 \(F_{scd}\)。
- **CD-Head**：解耦多任务头，输出四个分支：二值变化图（CD Map）、T1语义图（S1 Head）、T2语义图（S2 Head）、边缘图（Edge Map）。最终SCD结果根据CD Map阈值组合双时相语义图得到。
- 训练损失：\(L = \lambda_{cd}L_{cd} + \lambda_{s1}L_{s1} + \lambda_{s2}L_{s2} + \lambda_{edge}L_{edge}\)，分别对应BCE、CE、CE、BCE损失。

- **双向时序对齐的有效性**：通过对M-TBTT的设计，有效消除了时序顺序偏差，为区分不变区域一致性和变化区域过渡提供了对称基础。

## 7. 优点

1. **架构设计新颖**：
   - 提出M-TBTT实现**全局、双向、多尺度**的跨时相语义对齐，区别于传统的差分或单向交互。
