## 摘要
漫游车依赖感知系统维护空间地图，这些地图编码了物体和传感器质量（如距离可靠性、光照伪影、数据密度），并在部分可观测条件下指导数据融合、嵌入更新和导航。为研究这些耦合的感知-导航过程，我们提出CrossMaps，一种实时的置信度感知开放词汇语义地图构建流程，可从RGB-D数据构建可语言查询的地图。基于VLMaps风格的方法，CrossMaps将多尺度CLIP嵌入与置信度感知融合以及由短期记忆（STM）和长期记忆（LTM）组成的双记忆架构相结合。短期记忆利用几何、语义和时间置信度线索聚合带有噪声的视觉观测，而置信度高且一致性的单元则被提升至长期记忆，作为持久的语义地标。CrossMaps设计用于与基于Jetson Orin的UGV及SLAM协同部署，实时运行，生成语义热力图，可通过自然语言查询以引导漫游车导航。

## Abstract
Rovers rely on perception to maintain spatial maps that encode both objects and sensor quality (e.g., range reliability, lighting artifacts, data density), guiding data fusion, embedding updates, and navigation under partial observability. To study these coupled perception-navigation processes, we present CrossMaps, a real-time confidence-aware open-vocabulary semantic mapping pipeline that constructs language-queryable maps from RGB-D data. Building on VLMaps-style approaches, CrossMaps integrates multi-scale CLIP embeddings with confidence-aware fusion and a dual-memory architecture consisting of Short-Term Memory (STM) and Long-Term Memory (LTM). The STM aggregates noisy visual observations using geometric, semantic, and temporal confidence cues, while confident and coherent cells are promoted to the LTM as persistent semantic landmarks. Designed for deployment with a Jetson Orin-powered UGV alongside SLAM, CrossMaps runs in real time and produces semantic heatmaps that can be queried with natural language to guide rover navigation.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 扩展 VLMaps 范式，引入**短期记忆（STM）** 和**长期记忆（LTM）** 的双记忆表示，以及基于几何、语义、时间线索的**置信度感知数据融合**。
- STM 负责聚合近期观测，过滤噪声；LTM 只存储由高置信度和高一致性支持的可信语义地标。

### 关键技术细节
- **实时开放词汇语义映射**：
  - 将 RGB 帧划分为多尺度图像块（coarse 和 fine tiles），用预训练 CLIP ViT-L/14 编码为嵌入向量。
  - 利用深度图和 SLAM 位姿将采样点反投影到 3D 全局空间，关联对应图像块的融合嵌入，存入顶视网格地图。
- **置信度感知 STM 语义融合**：
  - 点级置信度：几何置信度（距离衰减、多视角提升）；语义置信度（新嵌入与已有单元格嵌入的余弦相似度）；时间置信度（衰减）。
  - 细胞级融合：每个网格单元维护语义累加器 \(S_\mathcal{C}\) 和置信度累加器 \(W_\mathcal{C}\)。融合时先时间衰减旧置信度，再通过软一致性门控（基于余弦相似度）对观测加权，最后执行置信度加权更新：\(S_\mathcal{C} \leftarrow S_\mathcal{C} + c_i \mathbf{e}_i\)，\(W_\mathcal{C} \leftarrow \lambda W_\mathcal{C} + c_i\)，归一化嵌入 \(\mathbf{e}_\mathcal{C} = S_\mathcal{C} / \|S_\mathcal{C}\|\)。
  - 更新后记录视角覆盖和语义一致性（coherence，即嵌入均值范数）。
- **STM 到 LTM 的晋升机制**：
  - 三个条件：高置信度（\(W_\mathcal{C} > \tau_c\)）、高语义一致性（\(coh_\mathcal{C} > \tau_h\)）、多视角支持（视角位掩码显示多样性）。满足条件的细胞被提升到 LTM。
  - 若新高置信度观测与已有 LTM 细胞矛盾，可替换旧条目，使长期地图也能适应性变化。
- **自然语言语义查询**：
  - 文本查询经 CLIP 编码后与各细胞嵌入计算余弦相似度，再乘以细胞一致性作为热力图值 \(H_\mathcal{C} = s_\mathcal{C} \cdot coh_\mathcal{C}\)，高置信度细胞影响排名，低置信度区域仍被显示。

### 算法流程（Algorithm 1）
1. 对当前 RGB 图像提取粗/细 tile 的 CLIP 嵌入。
2. 对每个采样深度点：反投影到 3D，获取对应 tile 嵌入，融合为点嵌入，估计几何置信度，分配到网格单元。
3. 对每个受影响的网格单元：更新嵌入、置信度、一致性。
4. 对每个 STM 细胞：若置信度>\(\tau_c\)、一致性>\(\tau_h\)、视角多样性足够，则晋升到 LTM。
5. 查询：编码文本，生成热力图，选择 top-1 导航目标。
