## 摘要
视觉Transformer（ViT）主导着计算机视觉领域。然而，它们依赖于刚性的块投影器，这限制了向对地观测（EO）的迁移，因为对地观测的输入模态、尺度和分辨率变化很大。我们提出了UniverSat，这是一种基于ViT风格的主干网络，围绕一个通用块编码器构建，该编码器将来自任意空间、光谱和时间分辨率，以及来自光学和非光学传感器的块，通过共享权重映射到一个共享的嵌入空间。这使得能够通过自监督在异构多模态语料库上训练单一模型，从而产生鲁棒的、与传感器无关的空间特征。我们在GeoBench、PANGEABench和SpectralEarth的标准对地观测基准上的分类和分割任务中取得了强劲的结果，验证了该方法。我们的代码和模型可在https://github.com/gastruc/UniverSat获取。

## Abstract
Vision Transformers (ViT) dominate computer vision. However, their reliance on rigid patch projectors hinders transfer to Earth Observation (EO), where input modalities, scales, and resolutions vary widely. We introduce UniverSat, a ViT-style backbone built around a Universal Patch Encoder that maps patches from arbitrary spatial, spectral, and temporal resolutions, and from both optical and non-optical sensors, into a shared embedding space with a shared set of weights. This enables training a single model on heterogeneous multimodal corpora via self-supervision, yielding robust, sensor-agnostic spatial features. We validate this approach with strong results across classification and segmentation on standard EO benchmarks from GeoBench, PANGEABench, and SpectralEarth. Our code and models are available at https://github.com/gastruc/UniverSat.

## 1. 论文的核心问题与整体含义

**研究动机与背景**：  
- 传统 Vision Transformer (ViT) 依赖固定的补丁投影器，难以直接迁移到对地观测（Earth Observation, EO）领域。  
- EO 数据具有高度异质性：包含光学、雷达、LiDAR、高程等多种模态；空间分辨率从厘米级到千米级；时间跨度从单次采集到密集时间序列；光谱通道数从 1 到 400+。  
- 现有 EO 基础模型多采用固定 patch size、固定波段数、固定时间采样，在处理不同传感器时需要强制重采样、波段选择或模态专用投影器，限制了通用性。  
- 论文目标：设计一个单一模型，能够处理任意空间、光谱、时间分辨率以及光学/非光学传感器，无需输入重采样，并通过自监督学习获得与传感器无关的鲁棒特征。

## 2. 论文提出的方法论

**核心思想**：  
用一个 **通用补丁编码器 (Universal Patch Encoder, UPE)** 替换 ViT 中固定的 patch projector，将任意形状的输入补丁映射到固定维度的嵌入空间，再通过跨模态融合、空间 Transformer 和灵活的输出分辨率预测，得到密集特征图。

**关键技术细节**：

- **通用补丁编码器 (UPE)**：  
  - **原子格式化**：将尺寸为 C×T×H×W 的输入 patch 分解为 C×T×I×S 的原子令牌（atom tokens），其中 I = hw 为子补丁内像素数，S 为子补丁数。每个标量值通过可学习傅立叶特征 (Learnable Fourier Features) 提升至 D 维嵌入。  
  - **轴向交叉注意力 (Axial Cross-Attention, ACA)**：按像素（I）、通道（C）、时间（T）、子补丁（S）的顺序，每次利用 ACA 模块折叠一个维度，同时扩展特征维度。ACA 只沿当前轴做交叉注意力，复杂度与原子数量呈线性关系。  
  - 输出：全局补丁嵌入 f ∈ R^(8D) 和子补丁嵌入 f_sub ∈ R^(S×4D)。

- **UniverSat 架构**：  
  - **补丁级模态融合**：每个 patch 对应的各模态嵌入通过 ACA 跨模态融合（折叠模态维度），得到单一多模态嵌入。  
  - **空间 Transformer**：由 B 个门控 Transformer 块处理所有 patch 嵌入，加入 RoPE 位置编码。  
  - **任意分辨率预测**：用户可在推理时指定目标地面采样距离，将 patch 嵌入通过双线性插值重采样到目标网格，再通过跨注意力恢复子补丁级精细细节。

- **自监督训练目标**：  
  - **跨模态对比损失 (L_con)**：相同 patch 的不同模态嵌入作为正样本，使用 InfoNCE 损失鼓励模态不变性。  
  - **线性多模态掩码建模 (LM3)**：扩展了潜在掩码图像建模至多模态多时间序列。对每个模态使用冻结的随机投影定义目标，预测器根据可见 patch 和指定时间戳预测掩码 patch 的表示，并用模态特定头映射到目标空间，再次使用 InfoNCE 损失。  
  - 最终损失：L = L_LM3 + λ_con L_con。  
  - 训练时通过大量随机丢弃（模态、时间、通道、patch）降低计算量并增强鲁棒性，约 90% 的原子被移除。

## 7. 优点

- **高效的自监督目标**：LM3 结合跨模态对比，利用冻结随机投影避免了崩溃，同时鼓励跨模态信息融合。

## 8. 不足与局限
