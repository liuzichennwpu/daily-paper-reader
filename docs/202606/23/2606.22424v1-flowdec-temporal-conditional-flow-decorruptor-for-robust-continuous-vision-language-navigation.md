## 摘要
连续环境中的视觉与语言导航（VLN-CE）要求智能体在未见场景中遵循自然语言指令。尽管大型模型（LMs）推动了VLN-CE的发展，但其性能仍因现实世界的视觉污染而严重下降，这是一个关键但未被充分探索的领域约束。我们引入了时间条件流去噪器（FlowDec），这是一种专为基于LM的VLN-CE设计的新型图像恢复框架。FlowDec集成了混合时间条件策略，使生成流路径与历史上下文对齐，并采用动作质心引导滤波来动态评估和整合输出。大量实验表明，FlowDec在导航准确性和生成延迟方面均优于最先进的去噪方法。我们的方法为在不可预测的现实条件下实现鲁棒具身导航建立了一个稳健高效的范式。

## Abstract
Vision-and-Language Navigation in Continuous Environments (VLN-CE) requires agents to follow natural-language instructions in unseen scenes. While Large Models (LMs) have advanced VLN-CE, their performance remains severely degraded by real-world visual corruptions, a critical yet underexplored domain constraint. We introduce Temporal Conditional Flow Decorruptor (FlowDec), a novel image restoration framework tailored for LM-based VLN-CE. FlowDec integrates a hybrid temporal conditioning strategy to align the generative flow path with historical context and employs action-centroid guided filtering to dynamically assess and integrate outputs. Extensive experiments demonstrate that FlowDec outperforms state-of-the-art decorruption methods in both navigation accuracy and generation latency. Our approach establishes a robust, efficient paradigm for resilient embodied navigation in unpredictable real-world conditions.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：FlowDec是一个面向导航感知的图像去污模块，基于**条件流匹配（CFM）**在潜在空间中建模从噪声到干净图像的生成过程。关键创新在于：
  - **混合时间条件策略**：在训练/推理中，结合三类条件：c₁: 仅当前帧增强图像；c₂: 当前帧增强+前一帧增强与真实图像的差异+动作标签；c₃: 当前帧增强+前一帧增强与去噪后图像的差异+动作标签。训练初期以c₂为主建立稳健污染建模，后期逐步用c₃替代c₂以弥合合成域与真实域的差距，同时c₁比例固定以维持单帧稳定。
  - **动作质心引导的潜在滤波**：利用原子动作（前进、左转、右转等）在连续帧间引起的潜在特征差异模式，统计构建每个动作的预期潜在差异分布（高斯分布）。推理时，若c₁生成的去噪潜在与前一帧的差异偏离对应动作质心的马氏距离超过阈值wθ，则调用c₃生成辅助结果并进行加权融合，从而在保持单帧稳定性与利用时序上下文之间自适应平衡。
- **关键技术细节**：
  - 模型基于U-Net结构的CFM网络，在预训练VAE的潜在空间操作（编码器E，解码器D）。损失函数为条件流匹配损失：\( \mathcal{L}_{\text{CFM}}(\theta) = \mathbb{E}[ \| (z_{c,gt,1} - z_0) - v_\theta(z_{c,gt,t}, c_i, t) \|^2 ] \)。
  - 为提高推理效率，起始点采用随机噪声与当前污染潜在插值：\( z'_0 = t_\theta z_0 + (1-t_\theta) z_{c,cor,1} \)（默认tθ=0.95），使用固定20步Euler求解器。
  - 动作质心在训练第一阶段从前一帧与当前帧的真实潜在差分构建，每个动作独立统计均值与对角协方差。

## 8. 不足与局限

- **实验覆盖**：
  - 对污染种类的选择主要参考了图像分类领域的常见列表，部分污染（如运动模糊、散焦）影响较小，实验分析集中于6种高破坏性污染，其他污染未被充分讨论。

  - 骨干仅用NaVid（和Uni-NaVid），属于LM基线性模型，未验证在非LM基VLN-CE模型（如模块化规划+控制）上的适用性。

- **理论不足**：
