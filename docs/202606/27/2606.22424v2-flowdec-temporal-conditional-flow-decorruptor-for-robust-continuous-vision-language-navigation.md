## 摘要
连续环境下的视觉与语言导航（VLN-CE）要求智能体在未见场景中遵循自然语言指令。虽然大型模型（LMs）推进了VLN-CE的发展，但它们的性能仍然受到真实世界视觉污染（一个关键但尚未充分探索的领域约束）的严重削弱。我们引入了时间条件流去污器（FlowDec），这是一个专为基于LM的VLN-CE设计的新型图像恢复框架。FlowDec集成了混合时间条件策略，以将生成流路径与历史上下文对齐，并采用动作中心引导过滤来动态评估和整合输出。大量实验表明，FlowDec在导航准确性和生成延迟方面均优于最先进的去污方法。我们的方法为在不可预测的真实世界条件下实现鲁棒的具身导航建立了一个稳健、高效的范式。

## Abstract
Vision-and-Language Navigation in Continuous Environments (VLN-CE) requires agents to follow natural-language instructions in unseen scenes. While Large Models (LMs) have advanced VLN-CE, their performance remains severely degraded by real-world visual corruptions, a critical yet underexplored domain constraint. We introduce Temporal Conditional Flow Decorruptor (FlowDec), a novel image restoration framework tailored for LM-based VLN-CE. FlowDec integrates a hybrid temporal conditioning strategy to align the generative flow path with historical context and employs action-centroid guided filtering to dynamically assess and integrate outputs. Extensive experiments demonstrate that FlowDec outperforms state-of-the-art decorruption methods in both navigation accuracy and generation latency. Our approach establishes a robust, efficient paradigm for resilient embodied navigation in unpredictable real-world conditions.

### 方法：核心思想、关键技术细节

本文提出**FlowDec**（Temporal Conditional Flow Decorruptor），一个专为LM-based VLN-CE设计的图像去损框架。核心是**条件流匹配（CFM）**，在潜空间修复图像。

#### 核心思想
- 将图像去损建模为条件生成问题：从随机噪声潜变量 `z0` 和当前损坏图像潜变量 `zc_cor` 出发，通过CFM网络预测速度场，输出去损潜变量。
- 关键在于利用**时序信息**与**导航动作语义**来引导生成，保证帧间一致性与导航任务相干性。

#### 关键技术细节

1.  **混合时序条件策略（Hybrid Temporal Conditioning Strategy）**：
    - 定义了三种条件 `c_i`，通过不同组合注入历史信息：
        - `c1`: 仅使用当前帧增强图像的潜变量 `[zc_aug, ∅, 0]`，作为主路径。
        - `c2`: 使用当前帧 + 前一帧增强与真实潜变量之差 + 上一帧动作 `[zc_aug, zp_aug - zp_gt, ap]`，用于早期训练稳定学习损坏模型。
        - `c3`: 使用当前帧 + 前一帧增强与去噪潜变量之差 + 上一帧动作 `[zc_aug, zp_aug - zp_denoise, ap]`，用于后期适配推理时的域差异。
    - **动态训练调度**：`c1` 权重固定，早期 `c2` 主导，后期逐渐被 `c3` 替代，使模型适应自身生成域。
    - **加速起始点**：推理时，从随机噪声与损坏潜变量的线性插值 `z0' = tθ*z0 + (1-tθ)*zc_cor` 开始生成，平衡去损能力与输入保真度。

2.  **动作质心引导潜伏过滤（Action-Centroid Guided Latent Filtering）**：
    - **动作质心构建**：在训练时，对每种原子动作（前移、左转15°等），收集连续两帧真实图像潜变量之差 `zp_gt - zc_gt`，计算其均值和方差，构成高斯分布 `N(μ_gt, σ_gt)`。这捕获了不同动作所对应的期望视觉变化模式。
    - **推理时自适应融合**：主路径默认使用 `c1`（稳定、无累积误差）。当前后帧去损潜变量差与对应动作质心的马氏距离 `w` 超过阈值 `wθ` 时，说明单帧产生不一致，此时启用辅助路径 `c3` 再次生成 `˜zc_decor`。若 `˜w < w`，则按加权组合融合两个结果，否则保持 `c1` 输出。这选择性使用时序信息，避免误差传播。
