## 摘要
在室内物流环境中运行的自主移动机器人依赖几何地图进行定位与导航，但缺乏对物体及其情境属性的语义理解。我们提出一种情境语义地图构建流程，该流程结合了基于SLAM的几何地图构建、基于SAM的实例分割、实例聚类以及VLM多视角推理，以生成编码几何结构、物体类别和物体可移动性的情境语义地图表示。通过在多个视角下聚合观测结果，并在零样本、开放词汇设置下查询VLM，该流程能够推断情境物体属性（此处以可移动性为例），无需特定任务训练或预定义物体类别。我们在两种提示策略下评估了三种VLM，并对流程进行了组件级分析。所提出的流程在语义分类上达到98.93%的mIoU，在物体可移动性估计上达到89.17%的mAcc。组件分析表明，VLM推理是情境理解的主要瓶颈，而实例聚类则是全景性能的主要限制。生成的语义地图支持动态室内物流环境中的情境感知过滤和鲁棒导航。

## Abstract
Autonomous mobile robots operating in intralogistics environments rely on geometric maps for localization and navigation, but lack semantic understanding of objects and their contextual properties. We present a contextual semantic mapping pipeline that combines SLAM-based geometric mapping, SAM-based instance segmentation, instance clustering, and VLM multi-view reasoning to produce a contextual semantic map representation encoding geometric structure, object class, and object movability. By aggregating observations across multiple viewpoints and querying a VLM in a zero-shot, open-vocabulary setting, the pipeline infers contextual object properties--here demonstrated through movability--without requiring task-specific training or predefined object categories. We evaluate three VLMs under two prompting strategies and conduct a component-wise analysis of the pipeline. The proposed pipeline achieves 98.93 % mIoU for semantic classification and 89.17 % mAcc for object movability estimation. Component analysis identifies VLM reasoning as the primary bottleneck for contextual understanding and instance clustering as the main limitation for panoptic performance. The resulting semantic map supports context-aware filtering and robust navigation in dynamic intralogistics environments.

## 2. 论文提出的方法论

### 核心思想
- 将几何建图（SLAM）与视觉感知（SAM实例分割）相结合，再通过实例聚类将同一物体的多帧观测聚合，最后利用VLM对聚合后的多视角图像进行零样本推理，同时输出物体的语义类别和可移动性属性（immovable / movable / mobile）。

### 关键技术细节
1. **几何建图（Geometric Mapping）**：使用2D激光扫描仪数据，经扫描点滤波（去除因相机与激光雷达空间偏移导致的图像平面重叠点）后，采用GMapping进行SLAM，生成2D点云地图 \( GM \)。
2. **实例分割（Instance Segmentation）**：对每帧RGB图像使用SAM的自动掩码生成管线，得到细粒度的类别无关分割掩码，并通过点-像素对应关系将掩码投影到地图坐标系。
3. **实例聚类（Instance Clustering）**：在地图空间中基于交并比（IoU）进行聚类，若同一物体在不同帧的投影实例的IoU > 0.3，则合并为该物体的多个观测。聚类结果既用于地图融合，也为VLM提供多视角输入。
4. **VLM推理（VLM-Based Reasoning）**：每个物体实例的多个观测以合成图像（全场景+绿框标注+近景裁剪）形式输入VLM，采用结构化提示词（包含可移动性本体论和JSON输出格式），在零样本设置下同时输出物体类别和可移动性。有两种提示策略：直接JSON（Direct JSON）和链式思考JSON（CoT JSON，在输出JSON前先输出推理步骤）。
5. **地图融合（Map Fusion）**：将几何地图、聚类结果、VLM推理结果融合，生成最终的上下文语义地图 \( SM \)，每个点附有语义类别、实例ID和可移动性属性。

### 公式与算法流程（文字说明）
- 传感器观测序列 \( O = \{(I_i, S_i)\}_{i=1}^T \)，其中 \( I_i \) 为RGB图像，\( S_i \) 为2D激光扫描。
- 几何地图 \( GM = \{p_i\} \)，\( p_i \in \mathbb{R}^2 \)。
- 上下文语义地图 \( SM = \{(p_i, cls_i, ins_i, m_i)\} \)，其中 \( cls_i \) 为语义类别，\( ins_i \) 为实例ID，\( m_i \in \{immovable, movable, mobile\} \)。
- 聚类采用IoU阈值0.3；VLM推理采用零样本、开放词汇，输出结构化JSON（若无法预测则返回“unknown”）。

## 6. 论文的主要结论与发现

- **最佳配置**：Gemini 3.1 Flash Lite + 直接JSON提示实现最高语义分类mIoU（98.93%），同时保持可移动性mAcc为89.17%。GPT-5.1的可移动性准确率最高（96.28%），但语义分类较差（74.38% mIoU）。
- **提示策略影响**：直接JSON优于CoT JSON（除GPT-o3外），CoT会降低语义分类精度。
- **多视角重要性**：禁用多视角导致mIoU和PQ大幅下降（超过30%），说明多视角对语义推理至关重要。
- **瓶颈分析**：VLM推理是可移动性估计的主要瓶颈（替换为真值后mAcc提升近11%）；实例聚类/关联是全景性能的主要限制（替换融合模块为真值后PQ提升约9%）。
- **系统整体性能**：完整管线达到98.93% mIoU、89.17% mAcc、89.78% PQ，验证了方法的有效性。

## 7. 优点

- **模块化设计**：各组件（几何建图、分割、聚类、VLM推理）可独立替换或升级，便于扩展和维护。
- **零样本、开放词汇**：无需预定义物体类别或任务特定训练，VLM直接推断类别和情境属性，适应灵活的内部物流场景。
- **多视角推理**：通过聚合同一物体的多次观测，增强对遮挡、模糊和视角变化的鲁棒性。
- **结构化输出**：VLM输出包含语义、可移动性和简短解释的JSON，便于集成到下游导航与规划系统。
- **系统级消融分析**：通过Oracle实验清晰识别各模块瓶颈，为后续改进提供方向。

## 8. 不足与局限

- **实验规模与泛化性**：仅在一个受控环境、18个实例、74帧数据上进行评估，缺乏多样化场景和更大数据量的验证，存在过拟合风险。
- **离线运行**：当前管线基于预录数据离线处理，未实现在线更新，无法实时响应物体状态变化。
