## 摘要
用于具身导航的视觉语言模型依赖从不断增长的轨迹历史中选择固定数量的帧。随着情节的延长，这种选择变得越来越稀疏，然而先前的研究显示，当帧数从8增加到64时，精度并无提升，这表明瓶颈不在于帧数量，而在于表示本身。稀疏的帧选择无法捕捉长程推理所需的结构化行为信号：转向模式、累积位移和路径拓扑。我们提出了BIT-Nav（具身导航的脑启发式轨迹记忆），该框架通过紧凑的学习型轨迹记忆来增强冻结的VLM导航流程。受海马体路径整合的启发——空间经验被压缩为结构化的情景痕迹而非以原始感官回放的形式存储——BIT-Nav在动作和相对位姿序列上训练了一个Bi-GRU编码器，通过对比学习目标（Multi-positive InfoNCE）对共享相同行为意图的轨迹前缀进行优化。得到的嵌入通过轻量级MLP投影到VLM令牌空间，并在每个决策步骤注入为一个单一的记忆令牌，以恒定的令牌成本用结构化运动历史来调节模型，而不受情节长度的影响。

## Abstract
Vision-Language Models (VLMs) for embodied navigation rely on selecting a fixed number of frames from a growing trajectory history. As episodes extend, this selection grows increasingly sparse, yet prior work shows no accuracy gain when scaling from 8 to 64 frames, suggesting the bottleneck is not frame quantity but the representation itself. Sparse frame selection cannot capture the structured behavioral signal that long-horizon reasoning requires: turning patterns, cumulative displacement, and path topology.   We introduce BIT-Nav (Brain-Inspired Trajectory Memory for Navigation), a framework that augments frozen VLM navigation pipelines with a compact learned trajectory memory. Motivated by hippocampal path integration, where spatial experience is compressed into structured episodic traces rather than stored as raw sensory replay, BIT-Nav trains a Bi-GRU encoder over action and relative pose sequences via a multi-positive InfoNCE contrastive objective on trajectory prefixes sharing the same behavioral intent. The resulting embedding is projected into the VLM token space via a lightweight MLP and injected as a single memory token at each decision step, conditioning the model on structured motion history at constant token cost regardless of episode length

## 2. 论文提出的方法论

### 核心思想
- 将离散动作序列转换为7维连续几何运动特征（累积位置、航向角、步进变化等），通过Bi-GRU编码器学习紧凑轨迹嵌入，再经轻量MLP投影器注入VLM的token空间，作为单一记忆token参与自注意力计算。
- 采用多正例InfoNCE对比学习目标，迫使共享相同起点和终点的轨迹在嵌入空间内聚拢，从而提取行为结构而非表面动作。

### 关键技术细节
- **特征工程**：每个动作映射为7维向量 \( m_t = [cx_t, cy_t, \sin\theta_t, \cos\theta_t, \Delta\theta_t, f_{\text{forward}}, f_{\text{turn}}] \)，包含累积位置、航向角、航向变化及动作类型指示符。
- **Bi-GRU编码器**：2层双向GRU，每方向隐藏维256，输出512维；采用掩码均值池化聚合全部有效时间步，再通过投影头（512→256→128）并L2归一化。
- **对比学习**：从3600个起点-终点对（每组10条增强轨迹）构建batch（6组×10=60条）。对每个锚点，同一组的9条为正例，其余50条为负例，使用多正例InfoNCE损失。
- **与VLM集成**：冻结预训练好的Bi-GRU编码器和Qwen3-VL-8B，仅训练一个两层MLP投影器（1024→256→4096），将128维轨迹嵌入映射到VLM的4096维token空间，作为单个<gru> token前置插入输入序列。
- **推理流程**：每步实时编码当前动作历史，生成一个轨迹记忆token，与当前视觉观察、稀疏历史帧、指令嵌入组成输入。

## 6. 论文的主要结论与发现

- 本文提出的BITE模块以恒定token成本（始终只注入一个额外token）实现了等效甚至优于线性增长文本历史的性能。
- Q1（累积航向估计）上，BITE+Qwen3-VL达到0.83准确率，而两种基线在长轨迹上均坍塌至≈0.07；Q2（动作频率推断）上，BITE与文本历史基线相当，但节省22× token成本。
- 定性实验显示，无轨迹记忆的模型倾向于基于当前帧重建历史，产生视觉上合理但事实错误的描述。BIT-Nav能准确报告转向序列和进度，表现出指令定位的涌现能力。
- 消融证实Bi-GRU优于Transformer/GRU/LSTM，7D特征提供最佳检索性能。

## 7. 优点

- **创新性**：将轨迹历史作为独立模态并以单个token注入VLM，受生物导航机制启发，概念简洁有效。
- **效率**：任何轨迹长度仅消耗一个额外token，远优于文本历史或帧历史的线性成本，且不牺牲性能。
- **通用性**：可插拔式增强现有VLM导航流水线，无需修改VLM架构，仅需训练轻量投影器。
- **对比学习设计**：多正例InfoNCE损失利用轨迹组结构，迫使嵌入捕获行为意图不变性，避免过拟合单一路径。
- **充分的理论动机**：从生物海马体路径整合到VLN历史的局限性，论述连贯。

## 8. 不足与局限

- **缺乏标准VLN基准评估**：作者承认当前未在R2R/RxR val-unseen上进行完整导航任务（成功率、SPL、导航误差）的端到端评估，仅做了理解性查询的定量实验。这使得与NaVILA等既有方法的直接比较缺失。
- **实验设置与实际导航差距**：测试使用离散动作序列和随机生成轨迹，未在具身智能体连续控制、传感器噪声和动态环境中验证。定性实验虽在Isaac Sim进行但案例有限。
- **对比基线不够充分**：未与HAMT、ETPNav等具有历史记忆机制的方法比较，也未与更近期的VLM+记忆方法对比。
- **轨迹编码仅依赖动作和几何信息**：未融合视觉地标、语言子目标等更丰富的模态，可能限制长期记忆的鲁棒性。
- **训练数据局限性**：数据集基于R2R/RxR的固定步长和转向角（0.25m, 15°），在实际机器人应用中步长和转角可能变化，泛化性需验证。
- **即时推理开销**：虽token成本低，但每步仍需运行Bi-GRU编码和投影器，且需保留完整动作历史用于编码，内存开销随步长线性增长，但相对于VLM推理仍是次要的。
