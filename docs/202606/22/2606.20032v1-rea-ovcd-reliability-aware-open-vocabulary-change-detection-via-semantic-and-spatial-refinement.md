## 摘要
与依赖预定义类别的传统遥感变化检测不同，开放词汇变化检测（OVCD）使用任意文本提示灵活地识别土地覆盖变化。然而，现有方法在建模变化时存在固有的权衡：实例级比较忽略了细粒度的语义变化（例如，部分建筑扩建），而直接像素比较由于语义模糊和空间不一致导致不可靠、不稳定的响应和边界伪影。为此，我们提出了一种高效的无训练可靠性感知开放词汇变化检测（ReA-OVCD）框架。它首先从像素级语义差异中推导出候选变化区域，以确保灵活和详细的定位。为确保可靠性，随后引入了一种协作细化策略，从语义和空间角度明确建模变化的有效性。具体来说，我们开发了一个语义变化推理（SCR）模块，通过联合分析分布差异和响应变化来重新评估变化，从而抑制偶然的不一致性同时保留可靠的语义转移。此外，设计了一个边界感知变化细化（BCR）模块，通过验证候选区域是否由可靠的内部像素支持来减轻由于边界不对齐和不确定性引起的伪影。在多个数据集（LEVIR-CD、WHU-CD、DSIFN和SECOND）上的大量实验表明，我们的方法持续优于最先进的方法，在更高计算效率下实现了2.13%到9.75%的F₁^C提升。代码已公开于https://github.com/Funny0101/ReA-OVCD。

## Abstract
Unlike traditional remote sensing change detection that relies on predefined categories, Open-Vocabulary Change Detection (OVCD) identifies land cover changes flexibly using arbitrary text prompts. However, existing methods suffer from an inherent trade-off when modeling changes: instance-level comparison overlooks fine-grained semantic variations (e.g., partial building extensions), while direct pixel comparison proves unreliable, yielding unstable responses and boundary artifacts due to semantic ambiguity and spatial inconsistency. To this end, we propose an efficient training-free Reliability-Aware Open-Vocabulary Change Detection (ReA-OVCD) framework. It first derives candidate change regions from pixel-wise semantic discrepancies to ensure flexible and detailed localization. To ensure reliability, it subsequently introduces a collaborative refinement strategy to explicitly model change validity from both semantic and spatial perspectives. Specifically, we develop a Semantic Change Reasoning (SCR) module that reassesses changes by jointly analyzing distributional divergence and response variation, enabling the suppression of incidental inconsistencies while preserving reliable semantic shifts. In addition, a Boundary-aware Change Refinement (BCR) module is designed to mitigate artifacts stemming from boundary misalignment and uncertainty through validating whether candidate regions are supported by reliable interior pixels. Extensive experiments across multiple datasets (LEVIR-CD, WHU-CD, DSIFN, and SECOND) demonstrate that our method consistently outperforms state-of-the-art approaches, achieving $\mathrm{F}_{1}^{C}$ improvements of 2.13\% to 9.75\% with higher computational efficiency. The code is publicly available at \https://github.com/Funny0101/ReA-OVCD

### 1. 核心问题与整体含义（研究动机和背景）
- **问题**：开放词汇变化检测（OVCD）旨在根据任意文本查询灵活识别遥感图像中的地物变化，而不依赖预定义类别。现有方法存在固有权衡：
  - **实例级比较**（如基于匹配的方法）虽能处理对象级变化，但会遗漏细粒度语义变化（如部分建筑扩建、局部填充）。
  - **直接像素级比较**（通过离散标签差异）能捕捉细节，但受限于开放词汇下语义预测的不稳定性——决策边界附近的标签翻转导致大量误检，且双时相图像间几何配准不足会沿边界产生条带状伪影。
- **动机**：需要一种既能保留像素级细粒度感知、又能抑制假阳性（语义模糊和空间不一致引起的）的可靠变化检测方法，且应避免微调以保持泛化能力。

### 2. 方法论：核心思想与关键技术细节
- **核心思想**：采用“候选生成 + 协作细化”的无训练范式。首先利用冻结的SAM-3对双时相图像进行语义解析，根据标签差异产生候选变化区域；然后通过**语义变化推理（SCR）**和**边界感知变化细化（BCR）**两个模块分别从语义可靠性和空间可靠性角度对候选区域进行验证和精炼。
- **关键技术细节**：
  1. **双时相开放词汇语义解析**：使用SAM-3（冻结）同时激活实例头和语义头，通过实例聚合（加权最大）、语义-实例融合（逐像素max）、以及类别存在度软抑制，得到双时相语义logit张量L₁, L₂ ∈ ℝ^{N×H×W}及标签图Y₁, Y₂。背景低置信度像素强制归为c₀。
  2. **语义变化推理（SCR）**：
     - 初始化硬变化图 H_change = I(Y₁ ≠ Y₂)。
     - 计算连续语义差异：Jensen-Shannon散度 D_JS 衡量概率分布形状差异；logit最大响应差值 D_logit 衡量响应强度变化。
     - 融合：S_fusion = 0.5·D_JS + 0.5·D_logit_norm。
     - 可靠变化得分 S_change = H_change · S_fusion，经阈值θ_change得到基础掩码 M_base。
     - 对每个查询类别c，进一步用类标签变化生成候选掩码 M_c_base。
  3. **边界感知变化细化（BCR）**：
     - 提取二值掩码 m_c₁, m_c₂的边界，用欧几里得距离变换得到每像素到最近边界的距离 d₁, d₂。
     - 空间置信度 R_c = min(d₁, d₂)，经sigmoid映射为权重 W_c（参数τ_c, s）。
     - 对M_c_base的各连通分量K_i，若其中高置信核心像素（W_c > 0.5）占比 ≥ ρ，则保留整个分量；否则剔除。
     - 最后形态学开运算和小区域去除作为后处理。

### 6. 主要结论与发现
- ReA-OVCD在所有BCD数据集的F₁^C上均最优：LEVIR-CD 82.53%、WHU-CD 90.31%、DSIFN 67.79%，分别超过第二名2.13%-9.75%。

### 7. 优点
- **无训练免微调**：完全利用冻结的基础模型（SAM-3），避免类别偏差，保留泛化能力，适应任意文本查询。
- **细粒度与可靠性兼顾**：通过SCR在连续概率空间建模分布和响应差异，而非简单离散标签，有效过滤由歧义导致的假阳性；通过BCR利用空间上下文验证区域完整性，避免边界收缩。
- **高效性**：整体设计轻量（元素级张量操作、稀疏候选区距离变换），延迟低、显存占用小，适用于大规模或实时场景。
- **模块可解释性**：SCR和BCR分别针对语义不确定性和空间不一致性，中间结果可视化验证了其各自功能。
- **统一框架**：同时兼容BCD和SCD，仅需调整类别查询设置。

### 8. 不足与局限
- **对稀疏或语义模糊类别效果有限**：在SECOND的“操场”类别上表现相对较弱（IoU^C 24.74%，F₁^C 39.67%），归因于该类样本少、与裸地或低植被视觉重叠大，导致基础模型过激活。
- **依赖基础模型质量**：性能上限受限于SAM-3的语义解析精度；若基础模型对某类先验不足（如罕见土地覆盖），可能产生系统性偏差。
- **边界参数敏感性**：虽大部分超参数固定，但不同数据集仍需微调阈值θ_change、τ_c等，通用性有待进一步提升（论文指出可能受数据集特性影响）。
- **实验偏差风险**：对比方法中部分结果引自原论文（†），可能因设置差异（如输入分辨率、后处理）引入轻微不公平；但作者已尽量保持条件一致。

- **无训练不代表无成本**：SAM-3推理仍需较大GPU显存（5.53GB），对边缘设备可能仍然较重。
