## 摘要
智能体导航系统需要一个基础导航模型，其观察策略可以在推理时从外部重新配置，因为指令跟随、物体搜索、目标跟踪和自主驾驶共享相同的感知-规划骨干，但在消耗视觉流方面需要根本不同的策略。我们提出Qwen-RobotNav，这是一个基于Qwen-RobotNav构建的可扩展导航模型，通过一个具有两个互补维度的参数化接口来解决这一问题：选择导航行为的多个任务模式，以及控制视觉历史编码方式的可控观察参数（例如，令牌预算、每个相机的权重）。通过在训练时对所有参数进行随机化，Qwen-RobotNav对任何推理时配置都具有鲁棒性，无需对Qwen-RobotNav主干进行任何架构修改。我们在1560万个样本上训练Qwen-RobotNav；与视觉-语言数据共同训练可防止在仅轨迹训练中观察到的退化为反应式动作序列映射器。参数化接口还使Qwen-RobotNav成为智能体系统的自然构建模块：对于长视距场景，上层规划器将目标分解为子任务，并在中间过程中动态切换Qwen-RobotNav的任务模式和上下文策略，通过重复调用同一模型来组合复杂行为。大量实验表明，Qwen-RobotNav在主要导航基准测试中取得了新的最先进结果。该模型从2B到8B参数表现出良好的规模扩展性，联合多任务训练开发了一个跨任务族迁移的共享空间规划基础，并在不同环境中对真实世界机器人展现出强大的零样本泛化能力。

## Abstract
Agentic navigation systems require a base navigation model whose observation strategy can be externally reconfigured at inference time, because instruction following, object search, target tracking, and autonomous driving share the same perception-planning backbone yet demand fundamentally different strategies for consuming the visual stream. We present Qwen-RobotNav, a scalable navigation model built on Qwen-RobotNav that addresses it through a parameterised interface with two complementary dimensions: multiple task modes that select the navigation behaviour, and controllable observation parameters (e.g., token budget, per-camera weights) that govern how visual history is encoded. With training-time randomization over all parameters, Qwen-RobotNav is robust to any inference-time configuration requiring zero architectural modification to the Qwen-RobotNav backbone. We train Qwen-RobotNav on 15.6M samples; co-training with vision-language data prevents the collapse into reactive action-sequence mappers observed in trajectory-only training. The parameterised interface also makes Qwen-RobotNav a natural building block for agentic systems: for long-horizon scenarios, an upper-level planner decomposes goals into sub-tasks and dynamically switches Qwen-RobotNav's task mode and context strategy mid-episode, composing complex behaviours from repeated calls to the same model. Extensive experiments show that Qwen-RobotNav sets new state-of-the-art results across major navigation benchmarks. The model exhibits favourable scaling from 2B to 8B parameters, with joint multi-task training developing a shared spatial-planning substrate that transfers across task families, and demonstrates strong zero-shot generalisation to real-world robots across diverse environments.

## 1. 论文的核心问题与整体含义（研究动机和背景）

**核心问题**：现有导航模型（如 NavFoM、ABot-N0）采用固定的观察策略（如均匀子采样、滑动窗口），无法在推理时根据任务需求动态调整视觉上下文。然而，指令跟随、目标跟踪、物体搜索、自主驾驶等任务虽然共享同一感知-规划骨干，却需要截然不同的视觉历史编码方式（如指令跟随需长期记忆，目标跟踪只需最近几帧，物体搜索在探索和接近阶段需要切换策略）。这种“一刀切”的方法限制了模型在多任务和智能体系统中的适应性。

**整体含义**：为了构建可部署于智能体导航系统的通用基础模型，需要将“观察上下文建模”提升为可外部控制的自由度，而非依赖固定架构。Qwen-RobotNav 通过参数化接口实现这一目标，使上层规划器能在推理时动态配置模型的观察策略，从而将同一模型作为可重用的导航原语，支持复杂的长视距任务。

## 2. 论文提出的方法论

### 核心思想
将多任务导航统一为**视觉观察上下文建模**问题，设计**参数化接口**，包含两个维度：
- **任务模式**（VLN、PointNav、ObjNav、Tracking）：选择导航行为。
- **可控观察参数**：视觉令牌预算(\(B\))、时间衰减(\(\gamma\))、每相机权重(\(w_c\))、帧采样模式(\(m\))、每图像令牌下限(\(b_{\min}\))/上限(\(b_{\max}\))。

训练时对所有参数进行随机化（\(\gamma \sim U[1,3]\), \(B \sim U[2048,4096]\), \(w_c\) 按相机范围采样），使模型对任意推理时配置鲁棒，无需任务特定微调。

### 关键技术细节
1. **任务自适应观察编码**（Algorithm 1）：
   - 对 \(T\) 时间步和 \(N\) 相机，先子采样至 \(T'\) 帧。
   - 计算时间权重 \(\omega_t = \exp(\gamma \cdot t/(T'-1))\)，\(\gamma\) 控制近期偏置。
   - 联合权重矩阵 \(W[t,c] = \omega_t \cdot w_c\)。
   - 约束分配：每图像至少 \(b_{\min}\) 令牌，至多 \(b_{\max}\)，按比例分配剩余预算，迭代处理超限。
   - 根据分配令牌数决定图像分辨率（通过 ViT 补丁合并），保持宽高比。

2. **视角和时间标识**：使用自然语言标签（如“Time step 1 Front View <image>”）将视觉令牌与相机 和时间关联，无需架构修改。

3. **具身感知提示**：系统提示区分“机器人”和“汽车”，无需额外参数。

4. **动作预测**：4层 MLP 头将 Qwen3-VL 最终隐藏状态映射为 8 个路径点 \((x, y, \theta)\)（24维），使用 MSE 损失，归一化训练。

5. **训练策略**：
   - 联合损失：\(\mathcal{L} = \mathcal{L}_{\text{traj}} + \lambda \mathcal{L}_{\text{VL}}\)，\(\lambda=1\)。
   - 85% 导航轨迹数据 + 15% 导航相关视觉-语言推理数据（防止坍塌为反应式动作）。
   - 优化器 AdamW，峰值学习率 \(2\times10^{-5}\)（骨干）/ \(1\times10^{-4}\)（动作头），余弦调度。

## 7. 优点

- **创新性**：将“上下文建模”提升为可外部配置的一级控制，而非固定架构，是该领域首次。

## 8. 不足与局限

- **AlpaSim 零样本性能**：未达到专用驾驶模型水平（Alpamayo-R1），表明对复杂动态场景的泛化仍有提升空间。
