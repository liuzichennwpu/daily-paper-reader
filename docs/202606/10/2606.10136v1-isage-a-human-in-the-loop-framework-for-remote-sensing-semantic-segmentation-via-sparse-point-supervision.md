## 摘要
遥感中的语义分割需要昂贵的像素级标注，而几乎每个问题都需要新的数据集，因为模型很少能在传感器、平台或地理区域之间迁移。现有的人机交互框架通过辅助机制（伪标签、传播、CRF、基础模型提示、辅助头）将稀疏点击扩展为密集监督，所有这些都作用于模型的预测分布。在该分布中，一个自信的错误像素与一个自信的正确像素在构造上无法区分，因此任何读取该分布的规则都无法将两者分开；区分信号位于模型外部。本文假设，针对模型错误（而非任意像素）的专家点击足以匹配密集监督，且无需扩展机制。iSAGE（由专家引导的迭代稀疏标注）在一个集成的开源平台上实现了这一假设，其中误差加权损失放大了每次点击的梯度，而标注记录本身即是数据集，可扩展、可修正、可审计。实验采用最小工作量机制：每帧每类最多一个标注像素。在BsB Aerial数据集上，iSAGE恢复了密集监督的97.2%（在0.040%像素上达到74.79% mIoU），并呈现出对比性的类别动态：无定形类别（可渗透区域）从种子点开始饱和，而小类别（汽车）需要后期迭代的努力。在ISPRS Vaihingen（外部基准）上，iSAGE以0.011%的像素达到76.78% mIoU，与密集基线（76.65%）相当，并超过了所有已发表的方法。在同一管道下，四种输出读取机制（预算1-100x的oracle熵、阈值0.90-0.99的伪标签、基于CRF的传播、均匀随机）比iSAGE低7.4至14.5个百分点。在调查的31种方法中，iSAGE是唯一无需辅助机制运行的迭代式人机交互框架。

## Abstract
Semantic segmentation in remote sensing requires costly pixel-level annotations, and nearly every problem demands a new dataset since models rarely transfer across sensors, platforms, or geographies. Existing human-in-the-loop frameworks expand sparse clicks into dense supervision via auxiliary machinery (pseudo-labels, propagation, CRFs, foundation-model prompts, auxiliary heads), all operating on the model's predictive distribution. A confidently wrong pixel is indistinguishable from a confidently correct one in that distribution by construction, so no rule reading it can separate the two; the distinguishing signal is external to the model. This paper hypothesizes that expert clicks targeting confident model errors, not arbitrary pixels, suffice to match dense supervision, with no expansion machinery. iSAGE (Iterative Sparse Annotation Guided by Expert) realizes this hypothesis on an integrated open-source platform, where an error-weighted loss amplifies the gradient at each click and the annotation record itself is the dataset, extensible, correctable, and auditable. Experiments use a minimum-effort regime: at most one labeled pixel per class per frame. On BsB Aerial, iSAGE recovers 97.2% of dense supervision (74.79% mIoU on 0.040% of pixels) with contrasting class dynamics: amorphous classes (permeable areas) saturate from the seed, while small classes (cars) require late-iteration effort. On ISPRS Vaihingen (external benchmark), iSAGE reaches 76.78% mIoU with 0.011% of pixels, matching the dense baseline (76.65%) and exceeding all published methods. Under the same pipeline, four output-reading mechanisms (oracle entropy across budgets 1--100x, pseudo-labels across thresholds 0.90--0.99, CRF-based propagation, uniform random) plateau 7.4 to 14.5 pp below iSAGE. Across 31 surveyed methods, iSAGE is the only iterative human-in-the-loop framework operating without auxiliary machinery.

- **现有方法的局限性**：

- **核心假设**：专家仅点击模型自信错误的像素（而非任意像素）就足以匹配密集监督的性能，且无需任何辅助扩展机制。
- **论文贡献**：

  3. 开源集成平台，支持预测叠加、点击标注、记录持久化、重训练闭环。

## 2. 方法论：核心思想与关键技术细节
### 2.1 整体框架：迭代错误驱动精化
- **输入**：初始稀疏标注`S0`。
- **流程**：训练初始模型 → 生成预测 → 专家在错误区域（预测与视觉不一致处）点击单像素 → 扩充标注集 → 使用Error-Weighted Dice Loss (EWDL)重训练 → 重复N次。
- **严格限制**：每次迭代每帧每类最多标注1个像素（最坏情况测试）。
- **不采用任何标签扩展**：每个点击代表仅一个真实像素。

### 2.2 稀疏标注与训练
- 每个标注为`(x, y, class)`元组，不进行区域扩展、不生成伪标签。
- 未标注像素在损失计算中被忽略（贡献零梯度）。
- 通过卷积的平移等变性和感受野，单像素梯度可传播到整个特征图。

### 2.3 Error-Weighted Dice Loss (EWDL)
- **标准Dice损失**：对每个类c计算 `L_Dice = 1 - (2 * sum(y_gt * y_pr)) / (sum(y_gt) + sum(y_pr))`。
- **加权版本**：引入权重 `w(x)`：
  - 若预测正确（argmax == ground truth），`w(x) = 1`；
  - 若预测错误，`w(x) = λ`（默认λ=5）。
- 加权后损失：`L_EWDL = 1 - (2 * sum(w * y_gt * y_pr)) / (sum(w*(y_gt+y_pr)))`。
- 效果：放大错误像素的梯度贡献，迫使模型关注错误区域。

### 2.4 软件平台
- 集成四个子系统：标注界面、记录存储（JSON）、会话打包、训练后端（基于Segmentation Models PyTorch）。
- 训练后端可插拔；JSON记录可审计、版本控制、独立于UI共享。

## 6. 主要结论与发现
1. **性能匹配密集监督**：
   - BsB Aerial：iSAGE在0.040%像素上达到74.79% mIoU（密集97.2%）。
   - Vaihingen：iSAGE在0.011%像素上达到76.78% mIoU，超过所有已发表弱监督方法，并与密集基线76.65%相当。
2. **输出读取机制均无法超越**：
   - 神谕熵（最高67.85%）比iSAGE低8.93pp；
   - 伪标签（最高69.35%）低7.43pp；
   - CRF传播退化至62.25%；
   - 均匀随机与神谕熵几乎无差异。
3. **类别动态差异**：
   - 无定形类（可渗透区域）从种子点快速饱和；
   - 小物体（汽车）需要后期迭代大量努力，与随机选择差距最大。
4. **EWDL有效性**：
   - 与Focal损失相当，但设计与错误点击更一致；
   - λ=5最佳，过高（20）导致退化。
5. **架构无关性**：在4种架构上iSAGE均达到均匀密集监督的93-94%。

## 7. 优点
1. **概念简洁**：首次清除所有辅助机械，仅依靠专家点击自信错误，证明了该信号足以匹配密集监督。
2. **可审计性**：每个标注为独立元组，可修正、版本化，标注记录即是数据集。
3. **自然类平衡**：每个点击贡献相同（不论物体大小），避免类别不平衡。
4. **操作优势**：添加新类只需点击新实例；修正错误只需修改一个JSON项。
5. **降低认知负荷**：专家仅需对视觉明确区域判断，避免密集标注的疲劳和边界模糊决策。
6. **平台开源**：促进复现和扩展。

## 8. 不足与局限
1. **实验范围有限**：
   - 仅测试遥感航空影像（两个数据集）、RGB/IRRG光谱，未验证SAR、高光谱、医疗、工业检测等其他领域。
   - 缺乏多标注者研究，未测量标注者间变异性及其对迭代的影响（尽管论文推测迭代可约束变异）。
2. **资源与算力未报告**：无GPU型号、数量、训练时间，不利于准确复现和公平比较计算成本。
3. **点击形式单一**：仅支持单像素点击，不支持涂鸦、排除点击等（作者提及为未来方向）。
4. **假设专家在环**：不适用于非专家众包场景；依赖领域知识来识别自信错误。
