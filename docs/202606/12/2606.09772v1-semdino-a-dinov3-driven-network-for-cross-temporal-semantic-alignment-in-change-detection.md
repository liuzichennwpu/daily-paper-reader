## 摘要
语义变化检测（SCD）旨在同时定位土地覆盖变化并识别转变前后的语义类别。然而，现有方法存在跨时间对齐不足、多尺度表示薄弱以及对照明、季节和配准噪声引起的伪变化鲁棒性差等问题。为解决这些问题，我们提出了一种新颖的端到端语义变化检测网络SemDINO，它将双分支编码器、多尺度时间交互、语义净化、变化增强和解耦的多任务预测集成到一个统一框架中。具体而言，我们构建了一个双分支编码器，通过门控金字塔融合将CNN骨干网络和冻结的DINOv3特征相结合，从而获得丰富的多尺度语义表示。然后，提出了一种多尺度时间双向变换器交互（M-TBTT）模块，以实现全局跨时间特征对齐和信息交互。为进一步增强真实变化并抑制伪变化，我们协同引入了语义净化（SCP）、双向变化增强（BiChangeEnhance）和多尺度变化增强（MCE）模块。最后，设计了一个多分支CD预测头，以联合输出二值变化掩码、双时相语义图和边缘约束。在公开遥感CD数据集上的大量实验表明，SemDINO相比最先进方法具有优越的性能和泛化能力，尤其在存在干扰因素的复杂场景中。

## Abstract
Semantic change detection (SCD) aims to simultaneously locate land-cover changes and identify semantic categories before and after transition. However, existing methods suffer from insufficient cross-temporal alignment, weak multi-scale representation, and poor robustness to pseudo-changes caused by illumination, season, and registration noise. To address these issues, we propose a novel end-to-end semantic change detection network named SemDINO, which integrates a dual-branch encoder, multi-scale temporal interaction, semantic purification, change enhancement, and decoupled multi-task prediction into a unified framework. Specifically, we construct a dual-branch encoder that combines a CNN backbone and frozen DINOv3 features via gated pyramid fusion, enabling rich multi-scale semantic representation. Then, a multi-scale temporal bidirectional transformer interaction (M-TBTT) module is proposed to achieve global cross-temporal feature alignment and information interaction. To further enhance genuine changes and suppress pseudo-variations, we introduce semantic purification (SCP), bidirectional change enhancement (BiChangeEnhance), and multi-scale change enhancement (MCE) modules collaboratively. Finally, a multi-branch CD prediction head is designed to jointly output binary change mask, bi-temporal semantic maps, and edge constraint. Extensive experiments on public remote sensing CD datasets demonstrate that SemDINO achieves superior performance and generalization ability against state-of-the-art methods, especially in complex scenarios with interference factors.

  - **多尺度表示薄弱**：浅层特征保留细节但易受扰动，深层特征语义强但空间细节丢失；现有方法多依赖有限标注学习，跨场景泛化性差。
  - **对伪变化的鲁棒性低**：现有方法难以在复杂干扰下区分真实变化与伪变化。
- **研究动机**：利用大规模自监督预训练的基础模型（如 DINOv3）提供语义先验，弥补任务特定特征的不稳定性；设计对称双向时间交互机制消除时间顺序偏差；通过多阶段变化增强模块抑制伪变化、突出真实语义变化。
- **整体含义**：提出 SemDINO，一个以 DINOv3 驱动的端到端网络，通过融合 CNN 局部细节与 DINOv3 全局语义先验、多尺度双向时间注意力对齐、以及净化与增强流水线，实现精准的语义变化检测，并能灵活切换至二值变化检测任务，验证了特征表示的通用性。

## 二、论文提出的方法论

### 2.1 核心思想
- **组合双分支编码器**：冻结的 DINOv3 视觉 Transformer 提供鲁棒的全局语义特征；可训练的 CNN 骨干（ResNet50）+ FPN 提取局部纹理和多尺度上下文。
- **金字塔融合（PyFu）**：通过独立适应模块（SepAB）对齐 DINOv3 特征与 CNN 金字塔特征，再用双门控注意力（通道注意力+空间注意力）选择性融合，形成语义增强的多尺度表示。
- **多尺度双向时间 Transformer 交互（M-TBTT）**：在每一尺度上对称执行 T1→T2 和 T1←T2 两个方向的交叉注意力，更新两个时间状态，消除时间顺序偏差，为未变区域的一致性和变化区域的差异区分提供统一基础。
- **变化增强流水线（#FeaCE）**：包含三个子模块：
  - **BiChangeEnhance (BCE)**：基于特征差和共享上下文门控提取初始变化特征。
  - **Semantic Clean Purify (SCP)**：利用估计的变化掩码对未变区域进行跨时间特征混合以增强一致性，同时保留变化区域的语义差异。
  - **Multi-scale Change Enhancement (MCE)**：通过多尺度平均池化（1×、2×、4×）聚合变化证据，抑制局部伪变化，结合残差连接保留细节。
- **解耦多任务预测头（CD-Head）**：同时输出二值变化图、双时相语义分割图、边缘图，最终通过组合规则生成语义变化图（from-to）。该头可灵活替换为二值变化检测头，实现任务泛化。
- **损失函数**：多任务加权组合，包括二值交叉熵（变化检测和边缘）、交叉熵（双时相语义分割），权重 λ 可调。

### 2.2 关键技术细节（文字表述公式）
- **金字塔融合**：CNN 特征 \(F_{pt,i}\) 与 DINOv3 特征 \(F_{dt,i}\) 经 SepAB 适应、拼接、1×1 卷积投影后，依次通过通道注意力（基于全局平均池化和全连接层生成门控）和空间注意力（基于通道平均值和最大值经7×7卷积生成门控），进行元素乘法加权，最后与原始 CNN 特征残差相加得到 \(f_{t,i}\)。
- **M-TBTT**：对每个尺度 i，先计算 T1→T2 的交叉注意力输出 \(O_{1→2,i} = \text{Attention}(W_q f_{1,i}, W_k f_{2,i}, W_v f_{2,i})\)，更新 \(f'_{1,i} = f_{1,i} + g_{1,i} O_{1→2,i}\)；对称地更新 \(f'_{2,i}\)。门控 \(g\) 初始化为 0，实现渐进学习。
- **#FeaCE 流水线**：
  - BCE：初始变化特征 \(F_{BCE} = \phi_d(|f'_1 - f'_2|) \odot \sigma(\phi_g(f'_1+f'_2)) + \phi_r(|f'_1-f'_2|)\)。
  - SCP：由 \(F_{BCE}\) 生成变化掩码 \(M_{chg}\)，逆掩码 \(M_{nchg}=1-M_{chg}\)，在未变区域用门控混合另一时相特征得到干净特征 \(f'_{1,clean}, f'_{2,clean}\)。
  - MCE：计算干净特征差 \(D_{clean}\)，分别进行1×、2×、4×平均池化，与 BCE 的池化版本相乘（乘 sigmoid 权重），再上采样融合，最后残差加到 \(F_{BCE}\) 得到最终增强特征。
- **预测与组合**：CD-Head 由若干卷积层组成；最终语义变化图 \(Y_{scd}(p)\)：若变化概率低于阈值 τ 则为未变类，否则由 argmax 预测的双时相语义类别组成 from-to 编码。
- **优化算法**：SGD 优化器（动量0.9，权重衰减5e-4），多项式学习率衰减（power=1.5），初始学习率0.01，Batch Size 2，200 epoch。

## 六、论文的主要结论与发现

1. **SemDINO 在 SCD 任务上显著优于现有方法**：在 Landsat-SCD 上，OA 96.46%、mIoU 89.51%、SeK 62.24%、Fscd 89.92%，均超过第二好方法 BT-SCD。在 SECOND 上，OA 88.76%、mIoU 74.19%、SeK 24.53%、Fscd 65.27%，同样最优。
