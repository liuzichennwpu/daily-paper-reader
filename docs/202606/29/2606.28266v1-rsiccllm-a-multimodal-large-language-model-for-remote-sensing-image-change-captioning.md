## 摘要
遥感图像变化描述旨在描述双时相遥感图像之间的变化，具有重要的研究和应用价值。然而，现有方法大多依赖传统深度学习架构，受限于模型容量而性能受限。尽管大模型后训练技术在通用领域取得了巨大成功，但由于数据稀缺以及对细粒度变化理解的需求，直接迁移到遥感图像变化描述仍面临挑战。为此，我们提出RSICCLLM，这是遥感图像变化描述中首个用于大型视觉语言模型的后训练框架。具体而言，我们设计了一种数据生成范式，发布了指令数据集RSICI，并建立了任务特定的遥感图像变化描述基准。我们进一步引入差异感知监督微调，以显式提取变化表征并引导模型感知和理解时间差异。此外，我们提出双负样本偏好优化，采用两种互补的负样本构建策略来构建偏好数据集RSICP，并进一步优化模型性能。大量实验验证了RSICCLLM的卓越能力，该模型仅用7B参数即取得了显著优于更大规模模型的结果。代码和数据集将在https://github.com/keaill/RSICCLLM公开提供。

## Abstract
Remote Sensing Image Change Captioning (RSICC) aims to describe changes between bi-temporal remote sensing images and holds significant research and application value. However, most existing methods rely on conventional deep learning architectures, and the limited model capacity constrains performance. Although large-model post-training techniques have achieved great success in general domains, their direct transfer to RSICC remains challenging due to data scarcity and the need for fine-grained change understanding. To address this, we propose RSICCLLM, the first post-training framework for large vision-language models in RSICC. Specifically, we design a data generation paradigm, release the instruction dataset RSICI, and establish a task-specific RSICC benchmark. We further introduce Difference-aware Supervised Fine-tuning to explicitly extract change representations and guide the model in perceiving and understanding temporal differences. In addition, we propose Dual-Negative Preference Optimization (DNPO), which employs two complementary negative-sample construction strategies to construct the preference dataset RSICP and further refine model performance. Extensive experiments validate the superior capability of RSICCLLM, which achieves outstanding results with only 7B parameters, surpassing models of substantially larger scales. The code and dataset will be made publicly available at https://github.com/keaill/RSICCLLM.

## 2. 方法论

### 核心思想
提出 RSICCLLM，首个针对 RSICC 的大模型后训练框架，分为三阶段：
1. **指令数据生成**（利用已有 RSICD 数据自动生成高质量指令）；
2. **差异感知监督微调**（显式提取变化表征，增强模型对时间差异的感知）；
3. **双负样本偏好优化**（构造偏好数据集，进一步细化模型输出）。

### 关键技术细节

#### 2.1 指令数据生成（RSICI 数据集）
- 输入：双时相图像对 + 对应的二值变化掩膜（几何先验）。
- 使用 Qwen-VL-Max 生成描述，通过几何约束、关键词校验（object, direction, verb, quantity）、去除幻觉与过长描述、人工复审等质量控制步骤，最终得到约 35k 训练样本、3k 域内测试样本（来自 LEVIR-CD、SYSU-CD），以及从 S2Looking、CDD 自动生成的约 5k 域外测试样本。
- 输出：Remote Sensing Image Change Instruction dataset (RSICI)。

#### 2.2 差异感知监督微调（Difference-aware SFT）
- **可微分空间配准**：消除非语义像素偏移。
- **差异图计算**：\( T = I_1 - I_2 \)，编码局部强度变化。
- **几何-纹理特征提取**：引入 8 种几何敏感卷积核（基于中心差分卷积 CDConv），包括标准卷积、CDConv、方向不对称算子、对称算子；对每个响应图应用 Hough 变换（公式 3）再经逆变换（公式 5）保留完整几何语义，得到 \(\Delta S\)（公式 6）。
- **交叉注意力融合**：以 \(T\) 为 query、\(\Delta S\) 为 key/value 进行融合（公式 7），得到最终变化表征 \(F\)，并增强原始视觉嵌入：\( V_{\text{enhanced}} = V_{\text{orig}} + F \)。
- **训练目标**：自回归交叉熵损失（公式 9），使用 teacher forcing；得到模型 RSICCLLM-sft。

#### 2.3 双负样本偏好优化（DNPO）
- **动机**：RSICC 缺乏显式标注，需构造高质量偏好数据集。
- **两种负样本构造策略**：
  1. **信息过滤选择**：将变化描述分解为 object, direction, change verb, quantity 等关键词；对候选 caption 过滤非关键词后计算与 ground truth 的 BLEU-1/2 与 ROUGE-1 平均相似度，选择处于阈值区间 (\(\tau_1, \tau_2\)) 的样本作为负样本（既不太难也不太易）。
  2. **替换生成**：直接替换 ground truth 中的关键词（从同组替换池中抽取），生成语义错误但语法自然的负样本。
- **合并构建最终偏好数据集 RSICP**（20k 图像对）。
- **训练损失**：\( \mathcal{L} = \mathcal{L}_{\text{DPO}} + \lambda \mathcal{L}_S \)，其中 \(\mathcal{L}_{\text{DPO}}\) 为标准 DPO 损失（公式 15），\(\mathcal{L}_S\) 为反向 KL 散度约束（公式 16）以稳定训练。

- RSICCLLM（7B 参数）在域内测试集上**全面超越所有对比方法**（包括 235B 的 Qwen3-VL-235B 和 241B 的 InternVL-3.5-241B），BLEU-4 达 62.78，SBS 达 82.72，相对提升约 10%~60%。
