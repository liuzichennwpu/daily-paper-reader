## 摘要
随着大规模基准数据集和现代检测架构的发展，遥感目标检测取得了快速进展。然而，现有的数据集和检测器仍然分散。大多数基准数据集关注有限的类别、固定的空间分辨率或单一传感器，而检测器仍然难以跨不同传感器和类别系统工作。在本文中，我们介绍了LEVIRDet-159，这是迄今为止最大、最全面的遥感目标检测数据集，包含159个类别、256万个边界框以及基于多层次分类体系的70万个细粒度标注。在每个关键规模维度上，LEVIRDet-159都超过了现有最大的遥感目标检测数据集，包含约7倍更多的图像、6倍更多的目标实例和4倍更多的类别。基于该数据集，我们设计了LEVIRDetNet，这是一个尺度层次感知的检测基础模型，用于通用遥感目标检测。LEVIRDetNet结合了在线视觉地面采样距离（GSD）预测、GSD条件查询调制与分配，以及用于混合粒度遥感监督的层次感知检测头。在严格的评估设置下，LEVIRDetNet展现出强大的跨域泛化能力。即使没有目标域训练或微调，它在9个外部基准数据集上实现了最先进的检测性能，在每个基准数据集的主要指标上平均比最强全监督竞争方法高出5.02 mAP。我们希望这项研究将推动跨不同类别系统、空间分辨率和传感器平台的强泛化遥感目标检测的发展。数据集和训练好的模型将在最终论文发布时于https://qinzheyang.github.io/LEVIRDet/ 上公开。

## Abstract
Remote sensing object detection has advanced rapidly with the development of large-scale benchmarks and modern detection architectures. However, existing datasets and detectors remain fragmented. Most benchmarks focus on limited categories, fixed spatial resolutions, or a single sensor, while detectors still struggle to work across different sensors and categorical systems. In this paper, we introduce LEVIRDet-159, the largest and most comprehensive remote sensing object detection dataset to date, with 159 categories, 2.56 million bounding boxes, and 700k fine-grained annotations under a multi-level taxonomy. In each key scale dimension, LEVIRDet-159 exceeds the corresponding largest existing remote sensing object detection dataset, containing approximately (7x) more images, (6x) more object instances, and (4x) more categories. Based on this dataset, we design LEVIRDetNet, a scale-hierarchy-aware detection foundation model for universal remote sensing object detection. LEVIRDetNet couples online visual Ground Sampling Distance (GSD) prediction, GSD-conditioned query modulation and allocation, and a hierarchy-aware detection head for mixed-granularity remote sensing supervision. Under stringent evaluation settings, LEVIRDetNet demonstrates strong cross-domain generalization. Even without target-domain training or fine-tuning, it achieves state-of-the-art detection performance on 9 external benchmarks, improving the strongest fully supervised competing methods by 5.02 mAP on average under each benchmark's primary metric. We hope this study will facilitate the development of strongly generalizable remote sensing object detection across diverse category systems, spatial resolutions, and sensor platforms. The dataset and trained models will be released at https://qinzheyang.github.io/LEVIRDet/, accompanying the final paper.

## 2. 方法论

### 核心思想
- 通过大规模多源数据统一与尺度-层次感知模型设计，解决跨域泛化难题。数据集构建不止于简单合并，而是系统性修正标注（几何校正、细粒度重标、新增实例），并采用多层次分类体系（30父类 + 159细分类）。模型则显式建模地面采样距离（GSD）、场景密度和语义层次。

### 关键技术细节

#### （1）LEVIRDet-159 数据集
- **规模**：174,488张图像，1735亿像素，2,563,973个实例，159个类别（含30个父类别，细分类包括45种飞机、13种车辆、71种舰船）。
- **来源**：来自20+公开遥感资源（检测、分割、分类等），涵盖卫星（SPOT、GF系列、Pléiades等）、航拍、地图服务（Google/Baidu），确保传感器多样性。
- **分辨率感知数据引擎**（三阶段）：  
  - **阶段I**：几何优先的父类别标注——统一为紧致水平框（tight-HBB），利用分割辅助审查检测异常框。直接继承23万框，几何校正42万框，新增148万框。  
  - **阶段II**：源盲细粒度重标——将父级框裁剪后隐藏来源，标注员根据视觉证据赋予最细粒度标签（无法确认则回退至父类）。  
  - **阶段III**：投影回检与全局校准——细粒度标签投影回原图，修正重复/遗漏/上下文错误。
- **层次结构**：多层次分类树，允许混合粒度标注（同一图像中不同物体具有不同语义深度），父类与子类不竞争。

#### （2）LEVIRDetNet 模型框架
- **基础架构**：DEIM风格的端到端检测器（DINOv3初始化ViT骨干 + Transformer编码器/解码器），全参训练（无LoRA）。
- **三个核心新模块**：

| 模块 | 功能 | 关键公式/流程 |
|------|------|---------------|
| **(a) 在线GSD预测器** | 从图像块提取多模态描述子，预测物理尺度GSD，生成条件嵌入。 | 对K个224×224块提取CNN、FFT、边缘描述子，通过门控融合与注意力聚合得到图像级表示，回归对数GSD。GSD嵌入 `z_g` 用于后续调制。 |
| **(b) GSD引导的查询嵌入与选择** | 用GSD嵌入调制初始解码器查询（FILM方式），并动态预测活跃查询预算。 | 查询更新：`˜q₀ = q₀ ⊙ (1+λγ_g) + λβ_g`；预算预测：从全局记忆、GSD嵌入、密度/尺度先验预测离散预算b∈{300,600,800}。辅助交叉熵损失 L_dyn。 |
| **(c) 层次感知检测头** | 使用层次多标签分类，对祖先、后代、同族设置不同权重，支持混合粒度训练；推理时折叠为单路径结果。 | 分类目标：祖先路径目标得分设为IoU质量r，其他为零；权重矩阵W对后代0，同胞0.25，同族0.5。层次分类损失 L_hcls。推理时先取路径最小得分，再取深度调整最大值作为最终预测。 |

- **匹配策略**：早期使用层次兼容匈牙利匹配（三成本：分类、L1、GIoU）；后期切换为质量感知代价 `C_switch = −ŝ_p·IoU(·)^α`。
- **训练策略**：两阶段——先预训练GSD预测器（约80万512×512 patches，1.6M iteration），再联合训练全模型120 epoch（AdamW，lr=5e-4，余弦退火）。输入分辨率1024×1024，批量级别随机缩放{896,960,1024,1088,1152}。

## 6. 主要结论与发现

- LEVIRDet-159 是迄今为止最大、最全面的遥感目标检测数据集，在图像数、实例数、类别数、细粒度分支、尺寸覆盖等方面全面超越现有数据集。
- LEVIRDetNet 在**无目标域训练的跨基准评估**中，9个外部基准的平均主要AP达到80.56，比最强全监督竞争者（平均75.54）高出5.02 mAP；比每个基准的最强单个竞争者平均高出3.33 mAP。
- 在阈值扫描对比中，LEVIRDetNet 的峰值mAP和实用阈值下的Precision/Recall稳定性均显著优于开集模型（LAE-DINO、SAM3）和单数据集训练的DEIMv2。
- 消融研究表明，GSD条件嵌入、动态查询分配、层次感知头均贡献了有效提升，特别是在小目标和中目标上。
- 数据统一（几何校正、细粒度重标、密集标注）与模型设计（尺度-层次感知）的耦合是实现强泛化检测的关键。

## 7. 优点

1. **数据集规模与质量空前来高**：159类、256万框、70万细粒度标注，且经过严格的几何与语义一致性修正（>90%为新标或修正），非简单聚合。
2. **领域知识深度融入模型设计**：在线GSD预测、动态查询预算、层次分类均针对遥感特性（分辨率变化、密度不均、混合粒度）定制，而非通用自然图像方法的简单迁移。
3. **严格的评估协议**：目标训练无关设置极具挑战性，证明了模型的真正泛化能力，而非过拟合到特定基准。
4. **实验全面且对比公平**：覆盖9个不同领域基准、数十种闭集/开集方法，消融设计覆盖所有关键组件。
5. **开源贡献**：计划公开全部图像、标注、代码、模型和来源许可证清单，便于社区复现和拓展。

## 8. 不足与局限

1. **计算资源信息不明确**：未给出完整训练所需GPU数量和时长，影响可复现性和效率评估。
2. **模型推理速度适中**：15.2 FPS（RTX 4090），虽优于开集模型但低于轻量级检测器（如YOLOv12x的96.3 FPS），在实时应用场景中可能受限。
3. **水平框协议限制**：当前仅支持水平框，未处理旋转检测（oriented object detection），而遥感中旋转物体（如飞机、舰船）很常见。如需扩展到旋转检测，需重新适配。
4. **细粒度覆盖有限**：深度细粒度仅扩展到飞机、车辆、舰船三大类，其他类别（如桥梁、体育场等）暂未下沉，未来需扩展更多地物。
5. **GSD预测依赖训练数据**：GSD预测器使用带有分辨率元数据的公开图像预训练，若遇到全新传感器或未知分布，预测精度可能下降，且无法完全替代传感器校准。
6. **标注人力成本高**：保守估计>10,

>10万标注工时，且需要专业遥感与地物知识，对标注员要求极高。这是当前数据集构建的主要瓶颈之一，也限制了数据覆盖范围的进一步扩大。

### 9. 未来工作方向

论文提出了若干前瞻性改进方向：

- **旋转框支持**：将当前的水平框（HBB）扩展至方向框（OBB），以更好地适配遥感中大量存在的旋转目标（如飞机、舰船）。
- **细粒度层次扩展**：进一步将深度细粒度覆盖至更多父类别，如桥梁、体育场、运动场等，以提升数据集的语义丰富度。
- **无监督GSD预测**：探索完全无监督或自监督的GSD预测预训练，降低对分辨率元数据的依赖，增强对未见传感器的适应性。
- **推理加速**：通过模型蒸馏、动态网络深度调整（根据GSD自动裁剪计算量）等方法，在维持高精度的同时提升FPS。
- **多任务基础模型**：将LEVIRDetNet拓展为支持目标检测、语义分割、变化检测等遥感通用任务的统一基础模型。

### 10. 总体评价

LEVIRDet-159数据集与LEVIRDetNet模型在遥感目标检测领域实现了关键突破：前者通过大规模、多源、多分辨率、细粒度的统一标注，极大缓解了现有基准的碎片化问题；后者通过显式建模地面采样距离、场景密度与语义层次，在无目标域训练的跨基准评估中展现了卓越的泛化能力。尽管存在水平框限制、标注成本高、推理速度适中等不足，但该工作的实验设计严格、对比公平、消融充分，有效证明了数据-模型耦合策略的可行性。开源计划将进一步推动遥感基础模型研究的发展，为后续工作提供了坚实的基础设施。
