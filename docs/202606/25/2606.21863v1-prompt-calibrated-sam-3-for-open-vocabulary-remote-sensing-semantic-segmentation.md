## 摘要
开放词汇语义分割（OVSS）在遥感图像中旨在分割超出固定标签空间的类别。最近的基于SAM 3的方法提供了有前景的免训练基础，但仍存在三个关键问题：（1）单个类名提示缺乏对复杂遥感类别的足够语义覆盖；（2）将每个类别扩展为多个提示会引入冗余的在线文本编码；（3）直接聚合多个提示响应会将噪声激活传播到最终预测中。为了解决这些问题，我们提出了ProC-SAM3，它从三个互补方面校准SAM 3的提示接口用于遥感OVSS。首先，我们构建一个离线提示池，其中类别匹配器将MLLM生成的候选分组为每个类别的集合，扩展约束进一步使用类别先验知识细化每个集合。其次，生成的文本嵌入被缓存并在所有测试图像中重用，消除了重复的文本编码。第三，我们引入存在引导残差融合，通过提示存在和置信度门控不可靠的解码器输出，然后进行峰值保持类聚合，保留小和稀疏物体的细粒度激活。在八个基准上的实验表明，ProC-SAM3实现了56.1%的平均mIoU，比之前最佳的免训练方法高出3.9个百分点。代码将在https://github.com/YanghuiSong/ProC-SAM3提供。

## Abstract
Open-vocabulary semantic segmentation (OVSS) in remote sensing images aims to segment categories beyond a fixed label space. Recent SAM 3-based methods provide a promising training-free foundation, yet three key issues remain: (1) a single class-name prompt lacks sufficient semantic coverage for complex remote sensing categories; (2) expanding each category into multiple prompts introduces redundant online text encoding; and (3) directly aggregating multiple prompt responses propagates noisy activations into the final prediction. To address these issues, we propose ProC-SAM3, which calibrates SAM 3's prompt interface for remote sensing OVSS from three complementary aspects. First, we construct an offline prompt pool where a Category Matcher groups MLLM-generated candidates into per-category sets, and Expansion Constraints further refine each set using category-specific prior knowledge. Second, the resulting text embeddings are cached and reused across all test images, eliminating repeated text encoding. Third, we introduce Presence-Guided Residual Fusion to gate unreliable decoder outputs by prompt presence and confidence, followed by peak-preserving class aggregation that retains fine-grained activations for small and sparse objects. Experiments on eight benchmarks show that ProC-SAM3 achieves an average mIoU of 56.1%, outperforming the previous best training-free method by 3.9 percentage points. Code will be available at https://github.com/YanghuiSong/ProC-SAM3.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：开放词汇语义分割（OVSS）旨在分割超出固定标签空间的类别，在遥感图像中具有重要应用。现有方法多为基于CLIP风格的patch级特征分割，但缺乏实例感知能力。近期SAM 3（Segment Anything Model 3）作为基础分割模型，凭借其可提示的掩码解码器，在遥感OVSS上已超越CLIP类方法，成为新的主流范式。
- **核心问题**：尽管SAM 3很强大，但如何为其适配遥感类别的文本提示接口成为关键挑战，具体表现为三个问题：
  1. **单一类名提示语义覆盖不足**：遥感类别外观多样（形状、尺度、场景），单个词不够。
  2. **多提示扩展导致冗余在线文本编码**：每个类别如果扩展为多个提示，每张图像都要重复编码，计算开销大。
  3. **直接聚合多提示响应会传播噪声**：简单平均或取最大会抑制小目标或引入错误激活。
- **本文目标**：提出ProC-SAM3，一种免训练、免GT标注的框架，通过校准SAM 3的提示接口来解决上述三个问题，在八个遥感基准上取得显著提升。

## 2. 方法论：核心思想、关键技术细节

### 2.1 整体框架
ProC-SAM3 包含三个阶段：**离线提示池构建（OPC）**、**提示优化的批推断（POBI）**、**存在引导残差融合（PGRF）**。三者分别对应“提示什么”、“如何编码”、“如何聚合”。

### 2.2 离线提示池构建（OPC）
- **核心思想**：利用多模态大模型（MLLM，具体为Qwen3-VL）为每个基类生成候选描述，再通过类别匹配器和扩展约束进行粗到细的语义精炼，形成紧凑、边界清晰的提示池。
- **步骤**：
  1. 对每个基类 $c_i$ 及其扩展约束 $EC_i$，使用Qwen3-VL生成多样化候选。
  2. **类别匹配器（CM）**：将每个候选映射到最优基类（例如“large vehicle”、“small vehicle”、“car”都映射到“vehicle”类）。
  3. **扩展约束投影**：利用类别先验知识（如属性、描述）丢弃违反约束的候选，保留语义一致且视觉可信的描述。
  4. 最终得到全局提示池 $P^* = \bigcup_{i=1}^N P_i$，每个提示 $q$ 保留其类别标签 $\pi(q)$。
- **特点**：离线构建，测试时无额外成本。

### 2.3 提示优化的批推断（POBI）
- **核心思想**：将离线提示池的文本嵌入一次性编码并缓存，避免每张图像重复调用文本编码器。
- **流程**：
  1. 预计算：$\mathcal{T}_{\{Q\}} = \text{TextEncoder}(P^*)$，缓存所有提示的文本嵌入。
  2. 在线推断：输入图像批 $I$，只一次视觉编码得到共享视觉特征 $F$。
  3. 将缓存文本嵌入分块（chunk），每块大小为 $B$，与 $F$ 共同输入掩码解码器：$Z_q = \text{MaskDecoder}(F, T_q), \quad q \in Q^{(t)}$。
  4. 解码器输出：语义掩码logits $S_q^{\text{sem}}$、实例掩码logits $S_q^{\text{ins}}$、存在分数 $\rho_q$、实例置信度 $k_q$。对实例掩码选置信度最高的作为代表，并定义基础响应 $S_q^{\text{base}}(u) = \max(S_q^{\text{sem}}(u), S_q^{\text{ins}}(u))$。

### 2.4 存在引导残差融合（PGRF）
- **核心思想**：在聚合多提示响应时，根据提示存在性、置信度和分支一致性进行门控，保留实例分支的锐利细节，同时抑制不可靠激活。
- **关键量**：
  - 一致性度量：$A_q = 1 - |S_q^{\text{sem}} - S_q^{\text{base}}|$
  - 正残差：$\Delta_q = [S_q^{\text{base}} - S_q^{\text{sem}}]_+$
  - 门控因子：$G_q = \rho_q \cdot k_q \cdot A_q$
- **融合公式**：$\tilde{S}_q = \rho_q \cdot (S_q^{\text{sem}} + G_q \odot \Delta_q)$
- **类聚合**：按像素取最大值：$\tilde{S}_i(u) = \max_{q:\pi(q)=i} \tilde{S}_q(u)$
- **最终预测**：$\hat{Y}(u) = \arg\max_i \tilde{S}_i(u)$
