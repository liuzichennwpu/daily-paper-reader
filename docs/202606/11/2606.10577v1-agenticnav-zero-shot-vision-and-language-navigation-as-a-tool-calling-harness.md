## 摘要
在连续环境中的零样本视觉语言导航（VLN-CE）近来随着大型视觉语言模型（VLM）的发展变得可行。然而，现有方法通常依赖学习到的航路点预测器来提出可导航的动作，这严重限制了模型的动作空间，并且未能有效利用深度输入。此外，记忆通常通过累积包含大量无关上下文的长文本或视觉历史，或通过检索跨剧情的经验来处理，这削弱了零样本设置。在本文中，我们重新思考零样本VLN-CE作为VLM与环境之间的智能接口，并提出了AgenticNav，这是一个轻量级导航框架，将动作、深度和记忆暴露为可调用的工具。动作工具允许VLM直接从RGB观测中选择目标像素，并将其转换为可执行的运动，而不是从预测的航路点中选择。深度通过按需像素深度工具暴露，使VLM仅在需要的地方请求精确的度量距离。对于记忆，AgenticNav提供一张紧凑的地图图像来总结历史轨迹，并配有一个召回工具，允许VLM选择性地重新访问过去的视觉观测，而不会使提示上下文过载。在R2R-CE基准测试中，AgenticNav在给定相同VLM主干的情况下，在零样本方法中建立了新的最先进（SOTA）性能。真实世界的验证进一步突显了其与先前方法相比的零样本泛化能力。消融实验表明，我们的动作工具设计优于传统的航路点预测器，而深度工具和智能记忆进一步促进了导航性能。

## Abstract
Zero-shot vision-and-language navigation in continuous environments (VLN-CE) has recently become feasible with large vision-language models (VLMs). However, existing methods typically rely on learned waypoint predictors to propose navigable actions. This severely limits the model's action space and fails to leverage depth inputs effectively. Moreover, memory is commonly handled by accumulating long textual or visual histories with substantial irrelevant context, or by retrieving cross-episode experiences, which weakens the zero-shot setting. In this paper, we rethink zero-shot VLN-CE as an agentic interface between the VLM and the environment, and present AgenticNav, a lightweight navigation harness that exposes action, depth, and memory as callable tools. Instead of choosing from predicted waypoints, the action tool allows the VLM to directly select a target pixel in RGB observations, converting it into executable motion. Depth is exposed through an on-demand pixel-depth tool, enabling the VLM to request precise metric distances only where they matter. For memory, AgenticNav provides a compact map image summarizing the historical trajectory, paired with a recall tool that allows the VLM to selectively revisit past visual observations without overwhelming the prompt context. On the R2R-CE benchmark, AgenticNav establishes new state-of-the-art (SOTA) performance among zero-shot methods given the same VLM backbone. Real-world validation further highlights its zero-shot generalization compared to prior methods. Ablations show that our action tool design outperforms traditional waypoint predictors, and that depth tool and agentic memory further contribute to navigation performance.

- **整体含义**：本文重新思考零样本VLN-CE的本质——它是一个VLM与环境之间的**智能体接口（agentic interface）**问题。接口设计（如何暴露动作、深度和记忆）对最终性能影响巨大，甚至比VLM本身的选择更为关键。

## 2. 论文提出的方法论

- **核心思想**：将VLN-CE建模为一个**工具调用框架（tool-calling harness）**，VLM通过调用三个核心工具与环境交互，无需训练航路点预测器。
- **关键技术细节**：
  - **动作工具（Action Tool）**：VLM直接在RGB全景图像中选择目标像素`(k, u, v)`，工具将其反投影为3D点，经过安全碰撞检查后转换为可执行的转向角`θ`和前进距离`ρ`。若不安全，返回`Reselect`信号要求VLM重选。
  - **深度工具（Depth Tool）**：VLM可调用`query_depth(P)`查询一组像素的度量深度，返回深度值、5×5邻域统计以及该像素若作为动作目标的转向角和距离预览（不实际移动）。这使VLM能精准比较空间距离。
  - **记忆工具：紧凑地图图像 + 选择性回忆工具**：维护一张历史轨迹的紧凑地图图像`B_t`（默认放入提示），以及一个缓存`C_t`存储过去观察的RGB图像。VLM可调用`recall(p,k)`从缓存中调取特定决策点某一视角的图像，避免提示上下文被无关视觉帧填满。
- **流程**：每个决策步，VLM接收多视角RGB、地图图像和历史对话，可多次调用深度和回忆工具获取证据，最终调用`move_to`或`stop`。安全检查失败触发`Reselect`。

## 6. 论文的主要结论与发现

- **主要结论**：AgenticNav在R2R-CE零样本设置下取得了新SOTA（GPT-5.5: SR 55%, SPL 48.41%），比相同骨干的SmartWay高11个点SR、13.37个点SPL。在Gemini-2.5-Pro骨干上也优于Open-Nav和EvoNav（严格零样本）。
- **关键发现**：
  - 动作工具（像素级直接选择）优于传统航路点预测器（消融实验：SR下降5点）。
  - 深度工具（按需查询）比输入深度图像更有效（SR从42%回升至53%，但仍低于完整方法55%）。
  - 智能记忆（地图+回忆）显著提升长程决策能力（无记忆时SR仅41%，仅有地图时51%，全方案55%）。
  - 工具化接口设计对性能的影响不亚于VLM本身的选择。

## 7. 优点

- **方法创新**：
  - 将动作空间从离散航路点扩展到连续像素级，充分利用VLM的视觉推理能力。
  - 深度作为按需工具而非稠密输入，降低VLM解析负担，提供精确空间证据。
  - 记忆机制通过紧凑地图+选择性回忆避免上下文过载，同时保持关键信息可访问。
- **实验设计**：
  - 公平复现主流baseline相同VLM骨干，确保对比可靠性。
  - 真实世界验证突出了sim-to-real泛化，展示了航路点预测器在真实场景中的局限性。
- **泛化性**：在多种VLM骨干（包括开源Qwen3.6-27B）上均取得有效结果，表明框架不依赖特定模型。
