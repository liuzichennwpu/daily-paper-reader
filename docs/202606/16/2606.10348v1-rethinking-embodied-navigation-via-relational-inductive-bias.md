## 摘要
物体导航要求智能体通过视觉观察在未知环境中定位目标。现有方法通常依赖开放词汇检测器或视觉语言模型（VLM）来回答“在哪里搜索”，但往往忽略了“什么不可信”——即哪些语义线索不可靠。开放词汇感知容易产生系统性误导证据：误报、过时的静态先验以及由于缺乏具身验证而导致的重复失败探索，这些会污染地图构建和决策制定。此类错误根植于真实场景中的结构化物体关系。为解决这一问题，我们提出DB-Nav框架，通过双重关系偏差重塑搜索空间。它将目标中心关系分解为激活偏差（传播上下文证据）和抑制偏差（通过感知混淆和动作级证伪抑制不可靠区域）。这些偏差被统一到一个关系激活-抑制探索图中，该图利用在线观测和失败访问调整前沿探索值。在ObjectNav基准上的实验表明，DB-Nav在成功率（SR）和路径长度加权成功率（SPL）上显著优于现有方法，提供了一个轻量级、可解释且鲁棒的导航框架，无需昂贵的在线VLM推理。

## Abstract
Object navigation requires an agent to locate a target in an unknown environment through visual observations. Existing methods typically rely on open-vocabulary detectors or vision-language models (VLMs) to answer where to search, but often overlook what not to trust - which semantic cues are unreliable. Open-vocabulary perception is prone to systematic misleading evidence: false positives, outdated static priors, and repeated failed exploration due to lack of embodied verification, which contaminates mapping and decision-making. Such errors are rooted in structured object relations in real-world scenes. To address this, we propose DB-Nav, a framework that reshapes the search space via dual relational biases. It factorizes target-centric relations into an Activation Bias (propagates contextual evidence) and an Inhibition Bias (suppresses unreliable regions via perceptual confusion and action-level falsification). These biases are unified into a Relational Activation-Inhibition Exploration Graph that modulates frontier exploration values using online observations and failed accesses. Experiments on ObjectNav benchmarks show that DB-Nav significantly outperforms existing methods in success rate (SR) and Success weighted by Path Length (SPL), offering a lightweight, interpretable, and robust navigation framework without costly online VLM reasoning.

## 1. 核心问题与研究动机

论文针对的是**开放词汇物体导航（Open-Vocabulary Object Navigation）**中一个被忽视的关键问题：现有方法过度关注“在哪里搜索”（where to search），却忽略了“什么不可信”（what not to trust）。开放词汇感知（如GroundingDINO、YOLO-World等）会产生系统性的误导证据：
- 高置信度的**虚假正样本**（如将椅子误检为沙发）；
- **静态先验**（如认为电视通常在客厅）一旦被矛盾的真实观测否定后难以更新；
- 缺乏具身体验验证导致**重复失败探索**，持续污染地图和决策。

这些错误并非随机噪声，而是根植于真实场景中**物体关系的结构化偏差**（如共现关系、视觉混淆关系）。因此，需要一种能同时利用正关系（激活）和负关系（抑制）的导航机制。

## 2. 方法论：DB-Nav框架

### 2.1 核心思想
将目标中心的物体关系分解为**两种协同偏差**：
- **激活偏差（Activation Bias）**：利用上下文共现关系传播正面搜索证据，鼓励探索有前景的区域；
- **抑制偏差（Inhibition Bias）**：通过显式建模感知混淆和动作级证伪，抑制不可靠区域（如视觉相似干扰物、已访问但未找到目标的区域）。

两种偏差被统一到一个**关系激活-抑制探索图（Relational Activation–Inhibition Exploration Graph）**中，在线将视觉观测和失败访问事件转化为语义源，动态调整前沿探索值。

### 2.2 关键技术细节

#### (1) 目标中心关系偏差构建
为每个类别ℓ分配三维类别-角色向量：  
`b_g(ℓ) = [c_g(ℓ), a_g(ℓ), i_g(ℓ)]^T ∈ {0,1}^3`  
- 目标类别/同义词：`[1,1,0]`（既提供提交证据，也提供激活）  
- 上下文共现类别：`[0,1,0]`（仅激活）  
- 视觉相似干扰物：`[0,0,1]`（仅抑制）

#### (2) 多视图多标签对象证据积累
每个物理对象簇o维护一个多标签集合，通过标签可靠性分数`ρ_o(ℓ)`（累积观测质量×融合置信度）进行**多标签竞争**，选出主导标签`ℓ*_o`，进而得到对象级关系证据向量`h_o = [h^c_o, h^a_o, h^i_o]`。

#### (3) 关系激活-抑制传播
定义局部关系图`G_t = (V_t, E_t)`，包含对象证据节点、上下文假设节点、负面证据节点、候选前沿节点。使用空间传播核`κ(p_v, p_u) = exp(-||p_v-p_u||^2 / R) · I[||p_v-p_u||≤R]`在局部邻域传播证据。

- **激活函数**：`A_t(f) = Σ h^c_o·κ(p_f, p_o) + Σ a_q·κ(p_f, p_q)`（来自目标证据 + 上下文假设）  
- **抑制函数**：`I_t(f) = Σ h^i_o·κ(p_f, p_o) + Σ a_n·κ(p_f, p_n)`（来自干扰物 + 负面证据节点，包括失败访问点）

#### (4) 偏差条件化探索与目标提交
- 前沿得分更新：`Ŝ_t(f) = [S0_t(f) + A_t(f)] / [1 + I_t(f) + C̄_t(f)]`，其中`S0_t`是BLIP-2语义响应，`C̄_t`是路径代价。  
- 选择得分最高前沿探索；当某个对象的提交证据`h^c_o`超过阈值θ时，切换为目标提交并调用目标搜索规划器（TSP）直接接近目标。

## 6. 主要结论与发现

1. DB-Nav在HM3Dv2上达到**74.5% SR和36.8% SPL**，显著优于同等条件下的VLFM（63.6%/32.5%），且不依赖在线LLM/VLM推理。
2. 激活偏差和抑制偏差均不可或缺，移除两者会导致SR分别下降9.1和4.7个百分点。
3. 多标签竞争机制对于鲁棒的角色分配至关重要（移除后SR下降7.8%）。
4. 相比频繁调用LLM的方法（如SG-Nav，平均122.3次/episode），DB-Nav零LLM调用，运行时间仅101.8秒，而其他方法高达1000+秒。
5. 即使在较弱检测器（仅GroundingDINO）下，DB-Nav仍比ApexNav高13.6个SR点，表明其有效利用噪声语义输出。

## 7. 优点

- **创新性视角**：首次将物体导航问题形式化为“搜索空间调制问题”，显式建模正负两种关系偏差。
- **轻量与高效**：无需训练，不依赖在线LLM，推理时间极短，内存占用仅~8GB，适合实际部署。
- **可解释性**：抑制偏差使得决策透明，可追溯哪些区域因何种原因被压制。
- **鲁棒性**：对检测器噪声有较强抵抗力，在弱检测器下仍大幅超越基线。

## 8. 不足与局限

- **实验环境**：仅在Habitat仿真中测试，未在真实机器人平台验证，仿真到真实的泛化性未知。
- **关系构建依赖**：类别-角色向量需预先定义（如通过LLM或人工），表5显示默认关系略优于LLM生成关系，表明关系定义的准确性仍影响性能。
- **场景类别覆盖**：HM3Dv1/v2仅6个目标类别，MP3D有21类但场景较少，未在更大规模（如HM3D全类别）上测试。
- **动态场景处理**：假定环境静止，无法处理物体移动或门状态变化。
- **超参数依赖**：传播半径R和阈值θ需人工设定，虽然敏感性分析显示较稳定，但最佳值仍需调参。
