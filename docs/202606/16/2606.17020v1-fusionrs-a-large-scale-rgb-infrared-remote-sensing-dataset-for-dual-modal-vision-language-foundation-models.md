## 摘要
遥感视觉-语言模型推动了地球观测理解的发展，但现有工作大多集中于RGB图像，红外数据中的互补信息尚未得到充分探索。红外图像提供独特的线索，包括热强度结构、物体边界和光照不变的场景特征，这些可以丰富超越常规RGB观测的视觉-语言学习。然而，目前仍缺乏用于遥感视觉-语言建模的大规模RGB-红外-文本数据集。为填补这一空白，我们提出了FusionRS，这是首个专为遥感双模态视觉-语言学习设计的大规模RGB-红外-文本数据集。FusionRS通过将多种公开RGB遥感图像转换为红外风格对应图像来构建，形成对齐的RGB-IR图像对。每对图像配有常规场景描述和红外感知描述，后者在保留语义内容的同时明确描述红外特有的视觉属性。基于FusionRS，我们训练用于RGB-IR联合理解的双模态视觉-语言基础模型。首先训练CLIP风格的模型以实现RGB-IR-文本对齐，然后微调生成式VLM用于双模态RGB-IR描述生成。实验表明，与仅RGB和非红外感知训练设置相比，FusionRS改进了RGB-IR对齐、红外到文本检索以及双模态描述生成。消融研究进一步验证了红外感知描述对于加强红外-语言对齐至关重要，凸显了模态特定文本监督对于更具可扩展性的RGB-红外遥感视觉-语言表示学习的重要性。

## Abstract
Remote sensing vision-language models have advanced Earth observation understanding, but most existing work remains centered on RGB imagery, leaving the complementary information in infrared data underexplored. Infrared images provide distinctive cues, including thermal intensity structures, object boundaries, and illumination-invariant scene features, which can enrich visual-language learning beyond conventional RGB observations. However, a large-scale RGB-infrared-text dataset for remote sensing vision-language modeling is still absent. To address this gap, we introduce FusionRS, the first large-scale RGB-infrared-text dataset designed for dual-modal vision-language learning in remote sensing. FusionRS is constructed by translating diverse public RGB remote sensing images into infrared-style counterparts, forming aligned RGB-IR image pairs. Each pair is associated with conventional scene captions and IR-aware captions that explicitly describe infrared-specific visual properties while preserving semantic content. Based on FusionRS, we train dual-modal vision-language foundation models for RGB-IR joint understanding. We first train CLIP-style models for RGB-IR-text alignment, and then fine-tune generative VLMs for dual-modal RGB-IR captioning. Experiments show that FusionRS improves RGB-IR alignment, infrared-to-text retrieval, and dual-modal captioning over RGB-only and non-IR-aware training settings. Ablation studies further verify that IR-aware captions are crucial for strengthening infrared-language alignment, highlighting the importance of modality-specific textual supervision for more scalable RGB-infrared remote sensing vision-language representation learning.

## 2. 方法论：核心思想、关键技术细节、算法流程

### 2.1 核心思想
- 将现有大规模RGB遥感图像通过**RGB-to-IR翻译模型**转换为红外风格图像，形成对齐的RGB-IR图像对。
- 为每对图像关联两种文本描述：**原始场景描述**（来自源数据集）和**IR感知描述**（由多模态大模型生成，明确描述红外特有的视觉线索）。
- 基于RGB-IR-文本三元组训练两类模型：
  1. **CLIP风格对比模型**：对齐RGB、IR、文本三种模态的嵌入空间。
  2. **生成式VLM**：通过指令微调实现红外图像描述生成和视觉问答。

### 2.2 关键技术细节
#### 数据构建
- **数据来源**：5个公开遥感数据集：RS5M（最大来源，约48.8万对）、SkyScript、NWPU、RSICD、RSITMD。总计60万样本，划分训练58万、验证1万、测试1万。
- **RGB-to-IR翻译**：使用**DiffV2IR**（基于扩散的可见-红外翻译模型，选用`after_phase_2.ckpt`检查点），将每个RGB图像转换为红外风格图像。输出为512×512分辨率、PIL RGB模式（视觉上类似灰度红外风格，但三个通道并非强制相同）。
- **文本注释与IR感知描述生成**：
  - 保留原始场景描述（源数据集的标题或类标签，经清洗过滤）。
  - 额外使用**Qwen2.5-VL-72B-Instruct**（通过OpenRouter API）生成IR感知描述。输入包括RGB图像、红外图像和原始文本，输出描述需保留场景语义并明确描述红外视觉特征（如灰度强度分布、高对比结构、亮暗区域、物体轮廓等）。
  - 最终获得49,068条IR感知训练描述、416条验证描述（经质量过滤）、10,000条测试描述。

#### 模型训练
- **CLIP风格对比训练**：
  - 每批次包含N个RGB-IR-文本三元组。使用对称对比损失：
    - `L_r,c`：RGB与文本对齐
    - `L_v,c`：红外与文本对齐
    - `L_r,v`：RGB与红外对齐
    - 总损失：`L_CLIP = (L_r,c + L_v,c + L_r,v) / 3`
  - 首先用全部60万三元组进行大规模预训练（使用原始描述）。
  - 然后使用IR感知描述子集（49,068条）进行**IR感知微调**，考虑三种设置：A-original（红外+原始描述）、B-iraware（红外+IR感知描述）、C-mixed（混合监督，包含红外+原始、红外+IR感知、RGB+原始、RGB-IR对）。

- **VLM指令微调**：
  - 基于IR感知描述子集构建指令数据，包括描述生成和视觉问答。
  - 采用**LoRA**（秩32，alpha=64，dropout=0.05）微调，学习率2e-4，余弦调度，预热0.03，bf16精度，单卡batch size=1，梯度累积8步，有效batch size=8，训练1轮。
  - 同样比较A-original、B-iraware、C-mixed三种设置。

### 2.3 算法流程（文字说明）
1. **数据构建**：收集RGB遥感图像 → 用DiffV2IR翻译成红外图像 → 清洗原始文本 → 用Qwen2.5-VL-72B生成IR感知描述 → 形成RGB-IR-文本三元组。
2. **对比学习**：用三元组训练CLIP模型，最小化三对模态间的对称对比损失，使RGB、IR、文本嵌入对齐。
3. **生成式VLM微调**：用IR感知描述子集进行LoRA微调，使VLM能理解红外图像并生成红外感知的输出。

## 6. 主要结论与发现

1. **FusionRS有效提升RGB-IR对齐**：使用FusionRS训练后，CLIP模型在RGB-IR跨模态检索上达到较高召回率（ViT-L/14 Mean R=66.22），且RGB-IR对齐优于IR-文本对齐，说明视觉间对应比红外-语言对齐更容易。
2. **IR感知描述至关重要**：在CLIP微调中，**C-mixed（混合监督）** 始终取得最佳性能（表14），表明原始描述+IR感知描述+RGB-IR对齐三者互补。单独使用IR感知描述（B-iraware）不如混合设置。
3. **VLM微调中IR感知描述显著提升红外相关任务**：B-iraware在Caption Auto、Caption IR Score、IR-cue QA、Object QA上大幅超越A-original，但在Scene QA上略逊，说明原始描述保留场景语义能力更强。C-mixed表现介于两者之间，混合监督对生成任务可能需更精细平衡。
4. **骨干泛化能力**：不同VLM骨干均受益于IR感知描述（表16），尤其H2RSVLM、InstructBLIP、Qwen2.5-VL-7B在IR-cue QA上达到90%以上准确率。
5. **RGB-IR对比训练是基础**：CLIP训练中580K-only基线（无IR感知描述）已能实现一定对齐，但加入IR感知描述后进一步提升。

## 7. 优点

- **首创性**：首个大规模通用RGB-红外-文本数据集，填补领域空白，为遥感双模态VLM研究提供基础资源。
- **数据构建策略高效**：利用现有RGB数据集翻译成红外，避免了昂贵且困难的红外传感器数据采集；同时通过生成IR感知描述弥补了原始文本缺少红外信息的不足。
- **双轨模型设计**：既训练对比模型（检索任务），又训练生成模型（描述与QA），全面评估双模态理解能力。
- **充分的消融实验**：系统比较了不同文本监督、不同骨干、不同训练设置，验证了各成分贡献。
- **开源潜力**：虽未明确开源地址，但数据集和训练框架设计清晰，便于复现和扩展。
- **实际意义**：红外模态在恶劣条件下（夜间、雾霾）有重要应用，该工作推动了遥感VLM向多模态实用化发展。

## 8. 不足与局限
