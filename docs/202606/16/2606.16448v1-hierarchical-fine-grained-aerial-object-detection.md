## 摘要
细粒度航空目标检测由现实世界目标类别的内在粒度驱动，对于遥感中的高级场景理解至关重要。现有方法大多继承了粗粒度目标检测的范式，仅依赖单标签监督，因此难以区分具有细微结构差异的型号级类别。然而，对于每个特定型号（如波音787），属性和层级等结构化先验知识提供了跨多个粒度的判别性语义。受此启发，我们提出了ExpertDet，一种融合专家信息线索以增强细粒度航空目标检测的方案。具体地，我们设计了视觉感知掩码属性建模（VMAM），通过从视觉线索中重建随机掩码的属性，将属性语义与视觉结构对齐，使检测器能够捕获细微的结构差异。我们进一步提出了层级视觉实例提升（HierVIP），它基于层级关系构建视觉原型树，并施加分类学感知约束，以在增强类别判别性的同时保持跨层级语义连续性。此外，我们为精确识别特定型号的舰船与飞机（PSP）构建了一个新的细粒度目标检测基准，分别涵盖106个舰船类别和30个飞机型号，是现有航空目标检测数据集中型号级类别最广泛的集合。我们在PSP基准上评估了最先进的目标检测算法。大量实验表明，ExpertDet在层级各级别上均优于其他细粒度竞争者。数据集、基准和代码见https://nnnnerd.github.io/PSP-Benchmark/。

## Abstract
Fine-grained aerial object detection, driven by the intrinsic granularity of real-world object categories, is crucial for advanced scene understanding in remote sensing. Existing methods largely inherit the paradigm of coarse-grained object detection, relying solely on single-label supervision and thus struggling to distinguish model-level categories with subtle structural differences. However, for each specific model (e.g., Boeing 787), structured prior knowledge such as attributes and hierarchies offers discriminative semantics across multiple granularities. Motivated by this, we present ExpertDet, a scheme that incorporates expert-informed cues to enhance fine-grained aerial object detection. Specifically, we design Vision-aware Masked Attribute Modeling (VMAM), which aligns attribute semantics with visual structures by reconstructing randomly masked attributes from visual cues, enabling the detector to capture subtle structural distinctions. We further propose Hierarchical Visual Instance Promotion (HierVIP), which builds a visual prototype tree based on hierarchical relations and imposes taxonomy-aware constraints to preserve cross-level semantic continuity while enhancing category discrimination. Moreover, we curate a new fine-grained object detection benchmark for Precise recognition of model-specific Ships and Planes from aerial imagery, PSP, covering 106 ship classes and 30 airplane models, respectively, featuring the most extensive collection of model-specific categories among existing aerial object detection datasets to date. We benchmark state-of-the-art object detection algorithms on the PSP benchmark. Extensive evaluation demonstrates that ExpertDet consistently outperforms other fine-grained competitors across hierarchy levels. The dataset, benchmark, and code are available at https://nnnnerd.github.io/PSP-Benchmark/.

## 2. 方法论

- **核心思想**：在标准目标检测框架基础上，引入两个轻量级模块，分别利用属性知识和层级知识来增强模型对细粒度特征的感知与判别能力。仅需在训练时启用这两个模块，推理时可完全移除，不增加额外计算开销。
- **关键技术细节**：
    1.  **Vision-aware Masked Attribute Modeling (VMAM)**：
        -   目的：建立属性语义与视觉特征之间的直接对应关系，引导模型关注决定型号差异的细微结构。
        -   流程：
            1.  对每个实例，将其对应的属性描述（如“翼展44.4米”、“机翼形状后掠”）进行分词，并随机遮蔽一部分token。
            2.  使用BERT编码器将遮蔽后的文本序列转换为文本嵌入。
            3.  通过RoI Align提取该实例的视觉特征。
            4.  设计一个视觉-语言编码器，融合视觉特征与文本嵌入，利用跨模态交互预测被遮蔽的token。
            5.  通过交叉熵损失最小化预测与真实token的差异，强迫视觉特征编码必要的属性语义。
    2.  **Hierarchical Visual Instance Promotion (HierVIP)**：
        -   目的：根据层级分类树结构组织特征空间，实现“类间可分，类内紧凑”，并保证层级间的语义连续性。
        -   具体做法：
            1.  基于给定层级结构，构建一个“视觉原型树”，树中每个节点代表一个类别（从根类别到型号级类别）。
            2.  采用动量更新的方式，用每个实例的特征去更新其对应路径上所有层级节点的原型。
            3.  提出了**Hierarchical Supervised Contrastive (HSC) loss**：对于层级树的每一层，将当前实例的特征与同层所有已激活的原型进行对比学习，拉近其与父类/本类原型，推远与其他错类原型。
- **最终损失函数**：`L = L_det + λ L_vmam + μ L_hsc`。

## 6. 主要结论与发现

- **ExpertDet有效**：在PSP基准和三个现有数据集上，ExpertDet在所有层级上均**一致超越**现有最佳方法。
- **现有方法的局限性**：在类别空间庞大、类间差异微小的PSP基准上，许多通用细粒度方法（如对比学习类）或长尾方法表现不佳，甚至低于其基线检测器，表明其假设（如简单拉大所有类间距）在高度拥挤的特征空间中失效。
- **专家知识的重要性**：属性和层级知识提供了强大的语义引导，提升了模型对细微结构的感知（VMAM）和对密集类别的区分能力（HierVIP）。
- **PSP基准的价值**：该基准提供了当前最丰富的型号级标签，并附有层级和属性知识，为细粒度检测提供了一个更具挑战性、更贴近真实应用的评测平台。

## 7. 优点

- **思想新颖**：巧妙地将专家知识（属性、层级）形式化为可训练的神经网络模块，而非依赖大规模人类标注或复杂的后处理规则。
- **方法简洁有效**：VMAM和HierVIP设计直观，且推理阶段无额外开销，易于集成到现有检测器中，显著提升性能。
- **实验极其充分**：对比方法数量多、类型全，消融实验细致，跨数据集验证了泛化能力，论证非常有力。
- **开源贡献巨大**：公开了包含106舰船+30飞机型号的PSP数据集，填补了大规模、高质量型号级航空目标检测数据集的空白，将有力推动该领域发展。

## 8. 不足与局限

- **属性知识依赖**：VMAM的有效性依赖于高质量的属性描述。虽然实验表明即使部分属性（随机选8/11）也有提升，但在属性不完整或噪声较大的真实场景中效果如何未完全验证。
- **层级结构固定**：HierVIP的树结构是预先定义的固定层级。在某些任务中，物体可能存在更复杂的、非严格的树状关系，该方法的适应性可能受限。
- **泛化范围有限**：虽然跨了三个其他数据集，但PSP基准本身仅涵盖舰船和飞机两类物体。该方法在其他细粒度领域（如遥感车辆、建筑）的泛化能力有待验证。
- **样本极端稀少的处理**：尽管在尾类上表现更好，但像“Pigeon”类，虽然ExpertDet从0提升到100，但其他方法也为0，这更多是因为数量极少（可能测试集中样本也少）导致效果不稳定。对于仅有1-2个训练样本的类别，任何方法的可靠性都值得警惕。
