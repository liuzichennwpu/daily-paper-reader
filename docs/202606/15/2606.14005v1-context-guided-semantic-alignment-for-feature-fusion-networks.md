## 摘要
特征融合网络是现代目标检测器中的基本组件，通过聚合多尺度特征来检测不同大小的物体。然而，由于不同金字塔层级的特征表示存在异构性，直接融合它们常常引入语义不一致。在本文中，我们提出了特征交互网络（FINE），一种轻量级的语义对齐模块，该模块在融合之前，通过跨层级的注意力机制利用高层级上下文引导来细化低层级特征。为了弥合结构差距并确保计算效率，我们引入了一种对齐感知令牌采样方法，该方法在不同尺度上对齐相应的空间区域，将注意力复杂度降低一个数量级。由此产生的注意力权重生成一个空间-通道调制图，该图经过上采样并通过残差逐元素调制应用于低层级特征。这种机制确保网络有选择地增强语义相关的像素，同时保留密集预测任务所需的亚像素定位精度。FINE 可普遍应用于各种检测器，并在不牺牲效率的情况下持续提高检测精度。

## Abstract
Feature fusion networks are fundamental components in modern object detectors, aggregating multi-scale features to detect objects of varying sizes. However, directly fusing features from different pyramid levels often introduces semantic inconsistency due to their heterogeneous representations. In this paper, we propose Feature Interaction NEtwork (FINE), a lightweight semantic alignment module that refines low-level features via high-level contextual guidance using cross-level attention prior to fusion. To bridge the structural gap and ensure computational efficiency, we introduce an Alignment-Aware Token Sampling that aligns corresponding spatial regions across scales, reducing the attention complexity by an order of magnitude. The resulting attention weights generate a spatial-channel modulation map that is upsampled and applied to the low-level features via residual element-wise modulation. This mechanism ensures that the network selectively enhances semantically relevant pixels while preserving the sub-pixel localization accuracy necessary for dense prediction tasks. FINE is generally applicable to various detectors and consistently improves detection accuracy without compromising efficiency.

## 1. 论文的核心问题与整体含义

### 研究动机与背景
- 现代目标检测器通常采用“骨干网络—颈部融合—检测头”的三段式架构。其中，颈部（如FPN、PANet）负责聚合多尺度特征，以检测不同大小的物体。
- 然而，不同金字塔层级的特征存在严重的**语义不一致**：高层特征语义丰富但空间粗糙，低层特征空间精细但语义不足。直接通过逐元素加法或拼接进行融合，会强制对准位置但未解决表示差异，导致**语义冲突**，表现为背景杂乱中的误分类和小物体检测困难。
- 已有工作如SENet、FaPN、AugFPN等尝试通道重标定或改进融合架构，但往往引入大量计算或缺乏即插即用性。注意力机制（如FPT、CLASS）用于跨层级交互，但密集像素级注意力在实时检测器中难以实用。

## 2. 论文提出的方法论：核心思想与关键技术

### 核心思想
- 提出**FINE（Feature Interaction NEtwork）**，一种轻量级的语义对齐模块，在融合之前**利用高层级上下文引导低层级特征**，通过**高效跨层级注意力**生成空间‑通道调制图，以**选择性增强语义相关像素并保留亚像素定位精度**。

### 关键技术细节

#### 2.1 整体流程
- 对于相邻低层特征 \(F_{low}\) 和高层特征 \(F_{high}\)，FINE 输出对齐后的低层特征 \(F_{low}^{aligned}\)，然后与上采样的 \(F_{high}\) 融合（公式3）。
- 三个子模块：**对齐感知令牌采样（AATS）**、**瓶颈多头跨层级注意力（Bottleneck Cross‑Level Attention）**、**残差空间‑通道调制（Residual Modulation）**。

#### 2.2 对齐感知令牌采样（AATS）
- 问题：不同层级有效感受野（ERF）不匹配，直接计算注意力计算量巨大且对应不可靠。
- 方法：**使用非重叠平均池化（无参数）分别对高低层特征进行下采样**，且采样核大小不相等，以同步ERF：
  - 高层：核大小 \(k\)；低层：核大小 \(r \cdot k\)，其中 \(r\) 为对齐感知采样比（默认为2，匹配骨干网相邻层级步长比）。
- 输出紧凑的 token 特征 \(\hat{F}_{low}, \hat{F}_{high}\)，注意力复杂度从 \(O(HW)\) 降至 \(O(N_{low}N_{high})\)，降低一个数量级。

#### 2.3 瓶颈多头跨层级注意力
- 将 \(\hat{F}_{low}\) 作为查询 (Q)，\(\hat{F}_{high}\) 作为键值 (K,V) 进行多头交叉注意力。
- 计算方式：\(Attention(Q_i, K_i, V_i) = Softmax(Q_i K_i^\top / \sqrt{d}) V_i\)。
- 输出拼接、投影后得到调制图 \(\hat{M}\)，再上采样至原低层特征分辨率得到 \(M\)。

#### 2.4 残差空间‑通道调制
- 由于调制图来自降采样 token，空间较粗糙，直接替换原始特征会丢失细节。
- 采用**残差乘法调制**：\(F_{low}^{aligned} = (F_{low} \odot M) + F_{low}\)。
- 保留原始高分辨率细节作为恒等映射，调制项作为数据相关的残差变换，仅调整特征响应强度。

## 6. 论文的主要结论与发现

- **FINE 在几乎所有检测器上均提升 AP**（+0.5～+2.1 AP），且**参数和 FLOPs 增长极小**（+1.0M 参数、+1.0~1.2G FLOPs）。
- 增益主要来源于**假阳性大幅下降（-9.93%）**和**小物体检测显著提升**（AP\(_s\) 相对提升最高 10.4%）。
- **AATS 是关键**：通过对齐 ERF 实现高效注意力，比密集注意力节省 93.3% 计算、99.9% 内存，且性能更优。
- **残差调制优于直接调制或直接替换**：保留细节，尤其是小物体。
- FINE 可**一键插入现有检测器**，且适用于**密集预测任务**（分割、全景分割），通用性强。
