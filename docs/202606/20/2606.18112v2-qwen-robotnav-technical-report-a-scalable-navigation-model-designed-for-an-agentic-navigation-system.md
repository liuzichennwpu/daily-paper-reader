## 摘要
自主导航系统需要一个基础导航模型，其观测策略可以在推理时从外部重新配置，因为指令跟随、目标搜索、目标跟踪和自主驾驶共享相同的感知-规划骨干，但对视觉流的消费方式要求根本不同的策略。我们提出了Qwen-RobotNav，这是一个基于Qwen-RobotNav构建的可扩展导航模型，通过一个参数化接口解决了这一问题，该接口具有两个互补维度：选择导航行为的多种任务模式，以及控制视觉历史编码方式的可控观测参数（例如，令牌预算、每相机权重）。通过在训练时对所有参数进行随机化，Qwen-RobotNav对任何推理时配置都具有鲁棒性，且无需对Qwen-RobotNav骨干进行任何架构修改。我们在1560万个样本上训练了Qwen-RobotNav；与视觉语言数据联合训练防止了在仅轨迹训练中观察到的退化为反应式动作序列映射器。参数化接口还使Qwen-RobotNav成为自主系统的自然构建模块：对于长周期场景，上层规划器将目标分解为子任务，并在剧情中间动态切换Qwen-RobotNav的任务模式和上下文策略，通过重复调用同一模型组合复杂行为。大量实验表明，Qwen-RobotNav在主要导航基准测试中取得了新的最先进结果。该模型在从2B到8B参数的扩展中表现出良好的可扩展性，联合多任务训练开发了一个跨任务族转移的共享空间规划基板，并在多样环境中展示了强大的零样本泛化能力到真实机器人。

## Abstract
Agentic navigation systems require a base navigation model whose observation strategy can be externally reconfigured at inference time, because instruction following, object search, target tracking, and autonomous driving share the same perception-planning backbone yet demand fundamentally different strategies for consuming the visual stream. We present Qwen-RobotNav, a scalable navigation model built on Qwen-RobotNav that addresses it through a parameterised interface with two complementary dimensions: multiple task modes that select the navigation behaviour, and controllable observation parameters (e.g., token budget, per-camera weights) that govern how visual history is encoded. With training-time randomization over all parameters, Qwen-RobotNav is robust to any inference-time configuration requiring zero architectural modification to the Qwen-RobotNav backbone. We train Qwen-RobotNav on 15.6M samples; co-training with vision-language data prevents the collapse into reactive action-sequence mappers observed in trajectory-only training. The parameterised interface also makes Qwen-RobotNav a natural building block for agentic systems: for long-horizon scenarios, an upper-level planner decomposes goals into sub-tasks and dynamically switches Qwen-RobotNav's task mode and context strategy mid-episode, composing complex behaviours from repeated calls to the same model. Extensive experiments show that Qwen-RobotNav sets new state-of-the-art results across major navigation benchmarks. The model exhibits favourable scaling from 2B to 8B parameters, with joint multi-task training developing a shared spatial-planning substrate that transfers across task families, and demonstrates strong zero-shot generalisation to real-world robots across diverse environments.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有的多任务导航模型（如 NavFoM、ABot-N0）采用固定的观测上下文策略（如均匀子采样或滑动窗口），无法在推理时根据任务需求动态调整观测历史的使用方式。然而，指令跟随、目标搜索、目标跟踪、自主驾驶等任务共享感知-规划骨干，但对视觉流的消费方式要求根本不同：指令跟随需要保留长程历史以便回溯地标，目标跟踪只需最近几帧，而目标搜索在探索阶段需要全局记忆、在接近阶段则需要局部关注。
- **研究动机**：为了实现一个可在自主导航系统中作为核心模块的基础导航模型，该模型必须支持外部（上层规划器）在推理时动态配置观测策略，而无需架构修改或特定任务微调。现有模型均不满足这一要求。
- **整体含义**：本文提出将多任务导航的核心挑战重新定义为**观测上下文建模**问题，而非架构设计问题。通过引入参数化接口，使导航模型成为一个可重配置的“导航原语”，从而能够被上层规划器灵活组合使用，构建复杂的长期行为。

## 2. 方法论

### 核心思想
- **统一任务公式**：将多种导航任务统一为**航点轨迹预测**问题，即基于文本指令和过去多视角图像序列，预测未来8个航点（每个含位置和朝向）。
- **参数化接口**：通过两个互补的配置维度暴露外部控制：
  1. **多种任务模式**（VLN、PointNav、ObjNav、Tracking），允许选择行为类型。
  2. **可控观测参数**：视觉令牌预算 B、时间衰减因子 γ、每相机权重 w_c、帧采样模式（随机/最新）。
- **训练时随机化**：所有观测超参数在每个样本独立随机采样（γ ~ U[1,3], B ~ U[2048,4096], 权重范围等），保证模型对任何推理配置鲁棒，不会过拟合单一配置。
- **自然语言视角与时间识别**：通过插入自然语言标签（如“Time step 0 Front View <image>”）而非位置编码，无需架构修改，利用预训练语言模型已有的空间语义知识。
- **具身感知提示**：通过系统提示（如“假设你是一个机器人/汽车”）区分不同物理平台，无需额外参数。
- **动作规划头**：轻量4层MLP，将LLM最后隐藏状态映射为24维输出（8航点×3自由度）。

### 关键技术细节
- **令牌分配算法（Algorithm 1）**：
  1. 根据帧采样模式选择T′帧。
  2. 计算时间权重 ω_t = exp(γ · t/(T′−1))，γ越大越偏向最近帧。
  3. 联合权重矩阵 W[t,c] = ω_t · w_c。
  4. 受约束分配令牌：每帧最小b_min，最大b_max，剩余按权重比例分配，超上限部分迭代重新分配。
- **数据增强**：
  - 指令重述（LLM生成同义句）。
  - 图像质量增强（Qwen-Image-Edit风格迁移）。
  - 相机高度、视场角、宽高比随机化。
  - 速度增强（多种步长）。
- **联合训练**：复合损失 L = L_traj + λ L_VL，导航轨迹数据（85%）+ 导航相关视觉语言推理数据（15%），防止模型退化为纯反应式动作序列。
- **训练优化**：AdamW优化器，余弦学习率，峰值为2e-5（骨干）和1e-4（动作头），梯度裁剪1.0，8B模型全局batch size=256，总训练2816 H100 GPU小时。

## 6. 主要结论与发现

- **参数化接口有效**：训练时随机化使模型能泛化到任意推理配置，且通过调整B和γ可显著影响性能（B=4608时SR比B=2048提高3.8%，γ=3.0时SR比γ=0.5提高1.7%）。

- **缩放规律**：从2B到8B参数，性能持续提升，尤其长期推理任务（EQA）受益更大。
- **联合训练优势**：与视觉语言数据联合训练防止动作序列退化，保持开放世界感知能力。
- **零样本真实泛化**：机器人在未见过的展览厅、公寓等环境中有效跟随指令，展示了强大的跨域迁移。
- **可重配置性**：在EQA系统中，上层规划器动态切换任务模式和观测配置，实现了长期规划，且比先前方法减少了77%的导航步骤。

## 7. 优点

- **创新点**：将多任务导航问题转化为观测上下文建模，赋予模型推理时可重配置性，是首个满足agentic系统需求的导航基础模型。
- **技术完整性**：从数据生成（T2V、VLM标注）到训练策略（随机化、联合损失）、从推理优化到agentic系统集成，整个pipeline闭环且实用。
- **实验广泛**：覆盖模拟和真实、多个任务族和多类对比，消融清晰。
- **可扩展性**：自然语言标签和提示设计使得支持新平台/新任务无需架构修改。
- **实际部署验证**：在真实机器人上演示了长环任务，验证了agentic接口的可行性。

## 8. 不足与局限

- **实验覆盖率不够全**：消融仅针对VLN-CE R2R的500 episode，未在其他任务（如跟踪、驾驶）上验证B和γ的影响。数据缩放实验也未包含跟踪和驾驶结果。
- **自主驾驶泛化受限**：在AlpaSim零样本评估中，性能（0.15/0.17分）远低于专用模型（0.72），表明跨域泛化到高度动态的长环驾驶场景仍存在困难。
