## 摘要
云去除旨在准确重建遥感图像中被云遮挡的地物。现有的基于Transformer的方法利用自注意力机制，通过对含云图像中的长距离依赖进行有效建模，展现出令人印象深刻的结果。然而，它们存在以下问题：1）自注意力的高计算复杂度限制了可扩展性；2）在注意力计算中将含云像素和干净像素都视为有效，会给后续层带来干扰，导致性能次优。为解决这些挑战，我们提出了自适应三角形Transformer用于云去除（ATT-CR），该模型有效降低了计算成本并减轻了含云像素的干扰。具体而言，它包含两个核心组件：三角注意力（TAN）和特征选择门控模块（FSGM）。TAN使用下三角和上三角矩阵近似Softmax注意力，计算复杂度为O(N)，显著降低了计算成本。而FSGM与TAN结合，自适应地区分含云特征和干净特征，从而最大程度地减少无效信息引入后续层。在云去除基准上的大量实验表明，ATT-CR相比现有方法具有更优越的性能。

## Abstract
Cloud removal aims to accurately reconstruct the ground objects obscured by clouds in remote sensing images. Existing Transformer-based methods utilizing self-attention have shown impressive results by effectively modeling long-range dependencies in cloudy images. However, they suffer from the following issues: 1) the high computational complexity of self-attention limits scalability; 2) treating both cloudy and clean pixels as valid within the attention computation brings disturbances in subsequent layers, leading to suboptimal performance. To address these challenges, we propose the Adaptive Triangular Transformer for Cloud Removal (ATT-CR), a model that effectively reduces computational costs and mitigates interference from cloudy pixels. Specifically, it consists of two core components: Triangular Attention (TAN) and Feature Selected Gating Module (FSGM). TAN employs lower and upper triangular matrices to approximate Softmax attention with O(N) computational complexity, significantly reducing the computational costs. The FSGM, on the other hand, integrates with TAN to adaptively distinguish between cloudy and clean features, which minimizes the introduction of invalid information into subsequent layers. Extensive experiments on cloud removal benchmarks demonstrate that ATT-CR delivers superior performance compared to existing methods.

# ATT-CR 论文详细总结

## 1. 核心问题与研究动机
- **背景**：遥感图像云去除旨在重建被云遮挡的地物信息。现有基于 Transformer 的方法利用自注意力（Softmax）建模长距离依赖，效果显著。
- **问题**：
  - ① 自注意力计算复杂度为 **O(N²)**（N 为像素数），难以扩展到高分辨率图像。
  - ② 现有方法在注意力计算中将**云像素与干净像素等同对待**，导致后续层受干扰，产生颜色偏差、模糊等伪影。
- **目标**：设计一种既能降低计算成本，又能**自适应区分云与干净特征**的去云模型，兼顾性能与效率。

## 2. 方法论

### 2.1 整体架构（ATT-CR）
- 采用**多阶段编码器-解码器**结构（5 个 stage，编码器 Stage 1~3，解码器 Stage 4~5）。
- 每个 stage 包含若干 **Transformer 块**，每个块由**自适应三角注意力模块（ATAM）** 和**门控深度卷积前馈网络（GDFN）** 组成。
- 输入含云图像 **I ∈ R^{H×W×3}**，经 3×3 卷积提取浅层特征 **X**，经编码器-解码器后与输入残差连接得到最终无云图像。

### 2.2 核心模块：三角注意力（TAN）
- **动机**：线性注意力（如 φ(Q)φ(K)^T V）复杂度 O(N)，但存在**低秩瓶颈**（秩受限于通道数 d，而 d ≪ N），导致注意权重同质化，表达能力下降。
- **设计**：
  - 将 Q、K、V 沿通道分半为两组（heads/2 和 heads/2）。
  - 第一组计算**下三角注意力**：每个 Query 只关注自身及之前的 Key（掩码 I_{i≤j}）。
  - 第二组计算**上三角注意力**：每个 Query 只关注自身及之后的 Key（掩码 I_{i≥j}）。
  - 利用三角矩阵的**满秩性质**（非奇异三角阵秩 = N），避免低秩问题。
  - 仍保持线性复杂度 O(N)：利用前缀/后缀累积技巧计算 M_i 和 Z_i，实现递推。
- **公式**：
  - 下三角输出：`O1_i = φ(Q1_i) * (∑_{j=1}^{i} φ(K1_j)^T V1_j) / (φ(Q1_i) * ∑_{j=1}^{i} φ(K1_j)^T)`
  - 上三角输出类似。
  - 最终输出：`O = Concat(O1, O2)`
- **激活函数**：φ(x) = ELU(x) + 1。

### 2.3 多尺度 Token（MS-Tokens）
- 针对遥感地物尺度差异大的问题，对 K 和 V 使用不同核大小的**深度可分离卷积**（如 3×3、5×5）生成多尺度特征，增强细粒度与粗粒度信息。

### 2.4 特征选择门控模块（FSGM）
- **动机**：不同通道的光学传输特性不同，有些通道能穿透云层保留细节。需要让网络**自适应地抑制云区域、增强干净区域**。
- **设计**：
  - 输入特征 X 经两个 3×3 卷积 + LeakyReLU 和 1×1 卷积，生成门控值 **G(X)**。
  - 将 TAN 各尺度输出与 **G(X)** 进行**对位乘法**（Hadamard 积），得到调制后特征。
  - 门控值在空间和通道上动态调整：高值区域表示模型关注的干净/重要特征，低值区域表示被抑制的云区域。

### 2.5 损失函数
- 均方误差（MSE）损失：`L = (1/N) ∑ ||F(X_i, Θ) - Y_i||²`。

1. **性能优越**：在 RICE2 上 PSNR 达 **36.72 dB**（比 CR-former 提升 0.48 dB），在 T-CLOUD 上 PSNR 达 **31.12 dB**（提升 0.30 dB），在 SEN12MS-CR 上 PSNR 达 **29.97 dB**（提升 0.19 dB）。所有数据集 SSIM 均最高。

4. **FSGM 有效抑制云干扰**：门控值可视化显示 FSGM 能根据云密度动态调整通道和空间权重，减少云像素向下传播。

## 7. 优点
- **创新性**：首次将**三角矩阵的满秩性质**引入线性注意力，同时保持 O(N) 复杂度，理论上填补了线性注意力低秩的缺陷。
- **实用性**：FSGM 考虑**通道特异性**（不同波段穿透云的能力不同），实现了细粒度的自适应特征选择。
- **多尺度融合**：MS-Tokens 通过不同核深的卷积捕获多尺度地物，提升细节恢复。
- **全面性**：实验覆盖薄云、厚云、真实云、多光谱等多种场景，对比方法完整，消融实验严谨。
- **效率平衡**：在参数量、计算量、推理速度上均优于同等性能的 SOTA（如 CR-former 和 ACA-CRNet）。
