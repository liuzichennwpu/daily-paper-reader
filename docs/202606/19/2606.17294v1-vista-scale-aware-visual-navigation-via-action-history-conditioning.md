## 摘要
视觉导航基础模型（VNMs）有望实现端到端学习的导航策略，能够在不同实体和环境间进行零样本部署。为保持通用性，许多基于视觉的导航模型预测归一化动作。然而，这种归一化引入了一个关键的部署漏洞：对相同归一化轨迹应用不同的缩放因子会改变其物理几何形状，从而降低导航性能并增加碰撞风险。我们通过将模型条件化为归一化的动作历史与图像观察相结合来解决这一漏洞，为模型预测与机器人实际物理位移之间的关系提供明确的上下文。此外，当前的VNMs通常难以处理缺乏显著特征的视觉重复环境。为了解决这个问题，我们集成了一个DINOv3编码器，其更丰富的表示使我们的模型能够捕捉观测之间的空间和几何维度。VISTA对分布外环境具有鲁棒泛化能力，在室外、森林和办公室环境的零样本真实世界部署中实现了100%的目标预测准确率，平均跨越95%的检查点，展示了在未知环境中持续路径跟踪的能力。

## Abstract
Vision Navigation Foundation Models (VNMs) promise end-to-end learned navigation policies capable of zero-shot deployment across diverse embodiments and environments. To maintain generality, many vision-based navigation models predict normalized actions. However, this normalization introduces a critical deployment vulnerability: applying different scaling factors to the same normalized trajectory alters its physical geometry, which degrades navigation performance and increases collision risks. We address this vulnerability by conditioning the model on normalized action histories alongside image observations, providing explicit context on the relationship between the model's predictions and the robot's actual physical displacement. Furthermore, current VNMs often struggle in visually repetitive environments that lack distinct features. To resolve this issue, we integrate a DINOv3 encoder, whose richer representations enable our model to capture both spatial and geometric dimensions between observations. VISTA generalizes robustly to out-of-distribution environments, achieving 100% goal prediction accuracy in zero-shot, real-world deployment in Outdoor, Forest and Office settings, and an average of 95% checkpoints crossed, demonstrating consistent path following in unseen environments.

## 1. 论文的核心问题与整体含义

### 研究动机与背景
- **核心问题**：现有的视觉导航基础模型（如ViNT、NoMaD）为保持跨实体通用性，预测**归一化的动作**（2D航点除以训练数据集平均步长）。但在部署时，机器人速度或控制频率变化会导致不同的**缩放因子**，相同的归一化轨迹映射到不同物理几何形状，从而降低导航性能并增加碰撞风险。
- **根本原因**：模型仅依赖视觉观测推断步长，缺乏显式的尺度信息。视觉输入无法区分“快速机器人短暂减速”与“慢速机器人全速运行”，导致度量错位。
- **论文目标**：提出一种**尺度感知**的导航方法，在保持归一化动作通用性的同时，通过提供动作历史上下文让模型感知物理尺度，实现跨环境、跨实体的鲁棒零样本部署。

## 2. 论文提出的方法论

### 核心思想
- 通过**归一化动作历史条件化**（Action History Conditioning）让模型建立“过去归一化动作”与“观测到的视觉位移”之间的关联，从而推断当前部署步长，生成度量对齐的航点。
- 集成**DINOv3**作为视觉编码器，提供更丰富的空间和几何特征表示，增强在视觉重复环境中的泛化能力。

### 关键技术细节
1. **DINOv3 Tokenization**：使用DINOv3 ViT-S将观测图像序列和目标图像转换为patch tokens，经2倍下采样投影后输入Transformer。
2. **动作历史条件化**：将过去k-1个归一化动作（每个动作 = 物理位移 / 部署步长）通过MLP编码为与图像token同维度的token，与图像token拼接后输入Transformer解码器。这样模型可学习视觉位移与步长的关系。
3. **Transformer解码器**：包含6层多头注意力（512维，8头），结合2D RoPE位置编码和可学习时间嵌入。
4. **训练目标**：多任务损失，包括动作MSE损失（归一化航点）和距离MSE损失（归一化目标距离），平衡系数λ=0.5。**关键差异**：训练时计算每个样本的平均航点间距（步长）作为归一化因子，而非整个数据集的固定值。
5. **多间距训练**：以2~12Hz的采样频率从数据集中抽取轨迹，模拟不同机器人速度和控制频率，增强鲁棒性。

### 公式/算法流程
- 模型输入：观测图像序列\(O_t\)、归一化动作历史\(H_t=\{a_{t-k+1},...,a_{t-1}\}\)、目标图像\(o_g\)。
- 输出：归一化航点\(\hat{A}_t\)和归一化距离\(\hat{d}_t\)。
- 部署时：将归一化航点乘以部署步长\(\phi_{deploy}=v_{max}/f_{ctrl}\)得到物理航点。
- 训练损失：\(L_{total} = \lambda L_{action} + \mu(1-\lambda)L_{distance}\)，其中\(L_{action}\)为MSE，\(L_{distance}\)为归一化距离的MSE。
