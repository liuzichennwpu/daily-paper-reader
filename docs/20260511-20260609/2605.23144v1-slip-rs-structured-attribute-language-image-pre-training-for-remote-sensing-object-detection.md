## 摘要
现有的遥感目标检测语言-图像预训练受限于单一标签学习，该方法通过黑盒数据穷举开放集类别来获取细粒度表示，产生了与领域固有数据稀缺性不相容的依赖性。为突破这一瓶颈，我们提出SLIP-RS，建立了一种结构化属性解耦范式，将开放的类别空间映射到有限的、具有物理意义的属性空间，通过显式结构逻辑实现细粒度可判别性。该范式通过两大技术支柱实现：（1）结构化属性对比学习，通过组合属性增强强制学习解耦的内在视觉逻辑；（2）一致性属性可靠性引擎，利用一致性预测理论从噪声源中严谨提取高保真监督，构建了最大规模、包含超过1500万属性标注的数据集RS-Attribute-15M。大量实验表明，SLIP-RS在细粒度检测和跨域泛化方面取得了前所未有的性能，验证了结构化属性作为遥感重要基础的地位。代码：https://github.com/facias914/SLIP-RS。

## Abstract
Existing language-image pre-training for remote sensing object detection is constrained by Monolithic Label Learning, which relies on exhaustively enumerating open-set categories via black-box data to acquire fine-grained representations, creating a dependency incompatible with the domain's inherent data scarcity. To transcend this bottleneck, we propose SLIP-RS, establishing a Structured-Attribute Decoupling Paradigm that maps the open-ended category space into a finite, physically meaningful attribute space, unlocking fine-grained discriminability via explicit structural logic. This paradigm is realized via two technical pillars: (1) Structured-Attribute Contrastive Learning, which enforces the learning of decoupled intrinsic visual logic via combinatorial attribute augmentation; and (2) Conformal Attribute Reliability Engine, which leverages conformal prediction theory to rigorously distill high-fidelity supervision from noisy sources, yielding RS-Attribute-15M, the largest dataset with over 15 million attribute annotations. Extensive experiments demonstrate that SLIP-RS establishes unprecedented performance in fine-grained detection and cross-domain generalization, validating structured attributes as a vital foundation for remote sensing. ## 1. 论文的核心问题与整体含义（研究动机和背景）

- **现有范式的瓶颈**：当前遥感目标检测的语言-图像预训练（如借鉴CLIP的开放词汇方法）受困于“单一标签学习”范式。该范式依赖黑盒数据（大规模图像-文本对）穷举开放集中的类别，隐式学习细粒度表示，但在遥感领域存在两个不可逾越的障碍：
  - **数据驱动的可扩展性瓶颈**：遥感领域缺乏高语义密度的公开数据源，无法提供充足的细粒度监督信号。
  - **语义绑定导致可判别性丧失**：模型将每个类别（如“波音747”）视为不可分割的语义黑点，而非一组独立可组合的视觉属性（如“四引擎+后掠翼”），难以捕捉关键判别特征。
- **核心创新**：提出**结构化属性解耦范式**，将对象的语义重新定义为属性的结构化组合，而非单一标签。通过将无限类别空间映射到有限、物理可解释的属性空间，在无需穷尽细粒度标注的情况下解锁细粒度可判别性。
- **整体意义**：为遥感数据稀缺下的基础模型构建提供了新路径，实现了前所未有的细粒度检测和跨域泛化性能。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想：结构化属性解耦范式
- 将对象分解为正交、互斥的语义原语（如引擎数量、机翼形状），使模型学习组合推理而非机械记忆。
- **结构化属性字典**：对每个类别定义 \( D(c) = \{(K_m, V_m)\}_{m=1}^M \)，其中 \( K_m \) 为属性维度，\( V_m \) 为该维度的离散语义原语集合。满足维度正交性和状态互斥性。
- 对象实例的真实表示为属性集 \( A(x) = \{v_1, v_2, \dots, v_M\} \)。

### 2.2 结构化属性对比学习（SACL）
- **正样本构建**：
  - 对真实属性集进行随机打乱（强制置换不变性）和随机丢弃（模拟部分遮挡），生成随机语义视图。
  - 固定ProtoTag（粗粒度类别）在前，后续属性用“+”拼接。
- **负样本构建（反事实硬负样本挖掘）**：
  - 通过属性替换（将有效原语替换为同维度的冲突原语）生成邻近流形上的硬负样本，迫使模型验证局部原语。
- **对比损失**：对每个视觉实例构建专属正负样本集，计算InfoNCE损失，与标准对比学习不同，不使用批内共享负样本。

### 2.3 一致属性可靠性引擎（CARE）
- **Tune阶段**：基于专家验证的种子属性分类数据集微调教师模型（RemoteCLIP-ViT/32B + LoRA），获得细粒度教师RemoteCLIP-FG。
- **Calibrate阶段**：利用共形预测理论，对每个属性类别使用校准集计算非一致性分数，推导统计有效的阈值（控制错误发现率）。对稀有属性（少于10实例）采用保守固定阈值。
- **Scale阶段**：应用校准阈值对14个开源遥感检测数据集（RS-Attribute-O）和第三方数据（RS-Attribute-C）进行伪标签过滤，构建RS-Attribute-15M，包含超过1500万带属性标注的实例，是目前最大的属性级遥感检测数据集。

### 2.4 整体训练框架
- 基于Faster R-CNN检测器，使用RFLA标签分配策略，视觉骨干为ConvNeXT-T/L（初始化自DINOv3），文本编码器冻结为RemoteCLIP-FG。
- 对于无属性标注的类别（如Bridge），使用其他不同类别作为负样本。
