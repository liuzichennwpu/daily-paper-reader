## 摘要
红外-可见光目标检测通过结合多光谱图像的互补特征来提升检测性能。现有的骨干专用和骨干共享方法仍然存在模态共享特征严重偏差和模态特定特征不足的问题。为了解决这些问题，我们提出了一种新颖的检测框架WD-FQDet，该框架从低频和高频域的新视角显式地将红外和可见光模态中的模态共享和模态特定信息解耦，从而允许根据其频率特性定制融合策略。具体而言，提出了低频同质性对齐模块，通过跨模态注意力机制对齐跨模态的共享特征，以及高频特异性保留模块，通过多尺度梯度一致性损失保留模态特定特征。为了增强频域中的特征表示，我们提出了一个融合空间线索的混合特征增强模块。此外，考虑到同质和模态特定特征对目标检测的贡献在不同场景中有所不同，我们提出了一个频率感知查询选择模块来动态调节它们的贡献。在FLIR、LLVIP和M3FD数据集上的实验结果表明，WD-FQDet在多个评估指标上达到了最先进的性能。

## Abstract
Infrared-visible object detection improves detection performance by combining complementary features from multispectral images. Existing backbone-specific and backbone-shared approaches still suffer from the problems of severe bias of modality-shared features and the insufficiency of modality-specific features. To address these issues, we propose a novel detection framework WD-FQDet that explicitly decouples modality-shared and modality-specific information from infrared and visible modalities in the new view of low- and high-frequency domains, allowing fusion strategies tailored to their frequency characteristics. Specifically, a low-frequency homogeneity alignment module is proposed to align modality-shared features across modalities via a cross-modal attention mechanism, and a high-frequency specificity retention module is proposed to preserve modality-specific features through the multi-scale gradient consistency loss. To reinforce the feature representation in the frequency domain, we propose a hybrid feature enhancement module that incorporates spatial cues. Furthermore, considering that the contributions of homogeneous and modality-specific features to object detection vary across scenarios, we propose a frequency-aware query selection module to dynamically regulate their contributions. Experimental results on the FLIR, LLVIP, and M3FD datasets demonstrate that WD-FQDet achieves state-of-the-art performance across multiple evaluation metrics.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 利用小波变换将红外和可见光特征分解为低频（模态共享）和高频（模态特定）分量；分别设计对齐与保留模块；再通过混合增强和频率感知查询选择实现自适应融合。

### 关键技术细节
1. **小波特征分解与集成模块（WDIM）**  
   - 使用Haar小波将空间特征分解为LL、LH、HL、HH四个子带；将三个高频子带拼接后经逐点卷积降维，得到低频特征（F_L）和高频特征（F_H）。
   - 低频特征视为模态共享特征，高频特征视为模态特定特征。

2. **低频同质性对齐模块（LFHA）**  
   - 对红外和可见光的低频特征先进行通道交换初步融合，再经ECA注意力增强，最后通过跨模态注意力实现精确对齐：  
     \[
     f_L^i = \text{Softmax}\left( \frac{f(f_R^i) g(f_I^i)^T}{\sqrt{D}} \right) h(f_I^i)
     \]
   - 其中f、g、h为线性层，D为编码维度。

3. **高频特异性保留模块（HFSR）**  
   - 对每个模态的高频特征先使用多尺度卷积（3×3,5×5,7×7）捕捉细节，再通过HOG算子提取结构化边缘并残差融合。  
   - 两模态增强特征拼接后经深度可分离卷积压缩通道，得到融合高频特征。
   - 引入多尺度梯度一致性损失（L_grad）确保融合特征保留两模态细节：  
     \[
     L_{grad} = \frac{1}{N}\sum_{k=1}^3\left( \|f_H^i - G_k(f_{R_H}^i)\|_1 + \|f_H^i - G_k(f_{I_H}^i)\|_1 \right)
     \]
   - G_k为基于Sobel算子和空洞卷积的多尺度梯度提取函数。

4. **混合特征增强模块（HFE）**  
   - 将对齐后的低频特征与红外空间特征融合（增强全局结构），将融合后的高频特征与可见光空间特征融合（增强细节）。  
   - 采用PANet风格的特征金字塔：先自上而下FPN，再自底向上PAN，集成频率与空间线索。

5. **频率感知查询选择模块（FQS）**  
   - 对增强后的低频和高频特征分别通过MLP生成权重系数并加权。  
   - 将加权展平特征拼接后选取Top K作为初始查询。  
   - 通过频率感知交叉注意力（FACA）实现自适应融合：  
     \[
     \text{FACA}(\hat{z}_q, \hat{p}_q, \{l_i\}, \{h_i\}) = \sum_{m=1}^M W_m\left( \sum_{i,k} A_{miqk}W'_m(l_i(\phi(\hat{p}_q)+\Delta p_{miqk})) + \sum_{i,k} A_{miqk}W'_m(h_i(\phi(\hat{p}_q)+\Delta p_{miqk})) \right)
     \]
   - 该模块动态调整同质与特定特征的贡献权重，适应不同场景。

### 训练损失
- 总损失：\(L_{total} = L_{box} + L_{cls} + L_{grad}\)，其中L_box和L_cls沿用RT-DETR的定义。
