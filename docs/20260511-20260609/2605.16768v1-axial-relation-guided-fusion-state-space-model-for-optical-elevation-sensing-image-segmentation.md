## 摘要
多源遥感图像的语义分割是地球观测应用中的一项基础任务。现有方法往往在多尺度上下文建模不足和跨模态特征融合次优的问题上存在困难，限制了其在复杂高分辨率场景中的性能。为此，我们提出了轴向关系引导融合Mamba（ARG-Mamba），一种基于状态空间模型的框架，用于光学-高程遥感图像分割。具体来说，我们引入了多尺度状态空间模块，以线性计算复杂度捕获细粒度局部细节和全局上下文依赖关系。此外，设计了轴向关系引导融合模块，沿水平和垂直轴显式建模全局跨模态相关性，实现光学与高程模态之间的高效特征融合。在ISPRS Vaihingen和Potsdam数据集上进行的大量实验表明，我们的ARG-Mamba在保持良好计算效率的同时，持续优于最先进的方法。代码将在\url{https://github.com/oucailab/ARG-Mamba}公开提供。

## Abstract
Semantic segmentation of multi-source remote sensing images is a fundamental task for Earth observation applications. Existing methods often struggle with insufficient multi-scale context modeling and suboptimal cross-modal feature fusion, limiting their performance in complex high-resolution scenes. To this end, we propose Axial-Relation Guided Fusion Mamba (ARG-Mamba), a state space model-based framework for optical-elevation remote sensing image segmentation. Specifically, we introduce a Multi-Scale State Space Module to capture both fine-grained local details and global contextual dependencies with linear computational complexity. Moreover, an Axial-Relation Guided Fusion Module is designed to explicitly model global cross-modal correlations along horizontal and vertical axes, enabling efficient feature fusion between optical and elevation modalities. Extensive experiments conducted on the ISPRS Vaihingen and Potsdam datasets demonstrate that our ARG-Mamba consistently outperforms state-of-the-art methods while maintaining favorable computational efficiency. The code will be made publicly available at \url{https://github.com/oucailab/ARG-Mamba}.

## 1. 核心问题与整体含义（研究动机和背景）

多源遥感图像语义分割是地球观测中的基础任务，但现有方法存在两大不足：
- **多尺度上下文建模不够充分**：高分辨率遥感图像具有显著的多尺度特性（从小汽车到大建筑），而多数基于状态空间模型（SSM，如Mamba）的方法仅采用单尺度token序列，难以同时捕捉细粒度局部细节和粗粒度全局上下文。
- **跨模态特征融合次优**：光学图像提供光谱和纹理信息，高程数据（DSM）提供几何和结构线索，两者互补。但现有融合方法缺乏自适应、上下文感知的融合机制，导致语义相关特征未能有效增强。

为此，本文提出**ARG-Mamba（Axial-Relation Guided Fusion Mamba）**——一种基于状态空间模型的框架，专门用于光学-高程遥感图像分割，旨在以线性复杂度高效捕获长程依赖，并通过轴向关系显式建模跨模态相关性。

## 2. 方法论

ARG-Mamba采用**双流编码器-解码器架构**，包含两个关键创新模块：

### 核心思想
- **多尺度状态空间模块（MS-SSM）**：通过在不同空间尺度上执行状态空间建模，同时捕获长程全局依赖和细粒度局部结构。
- **轴向关系引导融合模块（ARGFM）**：沿水平（行）和垂直（列）轴分解稠密关系矩阵，显式建模全局跨模态相关性，实现光学与高程特征的高效融合。

### 关键技术细节

#### MS-SSM
- 输入特征图 \(x \in \mathbb{R}^{C \times H \times W}\) 沿通道维度分割为 \(N\) 个子特征 \(\{x_i\}_{i=1}^N\)。
- 每个子特征在对应扫描尺度 \(s_i\) 下，将特征图划分为 \(\frac{H}{s_i} \times \frac{W}{s_i}\) 个非重叠窗口，在窗口内执行SSM二维扫描（采用双向扫描，降低冗余）。
- 扫描结果经SSM处理后输出 \(\bar{y}_i \in \mathbb{R}^{C_i \times H \times W}\)，最后将所有尺度特征沿通道拼接，并通过线性投影和深度卷积（DConv）实现跨尺度交互。
- 默认使用4个尺度 \(\{1, 2, 4, 8\}\)，与遥感物体空间层级对齐。

#### ARGFM
- 输入光学特征 \(F_o\) 和高程特征 \(F_e\)，先投影为局部上下文增强特征 \(\tilde{X}_o, \tilde{X}_e\)。
- **轴向关系注意力层（ARAL）**：计算稠密关系矩阵 \(R = X_o X_e^\top \in \mathbb{R}^{HW \times HW}\)，然后分别对行和列进行卷积（Conv_row, Conv_col）降维，经Softmax得到权重向量 \(V_e\) 和 \(V_o\)，扩展后生成关系感知token \(X'_o, X'_e\)。复杂度从 \(O((HW)^2)\) 降至 \(O(HW(H+W))\)。
- **融合SSM块（Fus-SSM）**：将局部token \(\tilde{X}_o, \tilde{X}_e\) 与关系感知token \(X'_o, X'_e\) 交叉拼接，通过选择性扫描（SSM）建模长程依赖，再经线性投影和FFN输出 \(F'_o, F'_e\)。
- **交叉注意力与融合**：对 \(F'_o, F'_e\) 计算交叉注意力，然后线性投影得到融合特征 \(F_f\)，同时将 \(F'_o, F'_e\) 分别传回对应编码器流。

#### 整体架构
- 编码器：光学和DSM各有一个四阶段分层编码器，每阶段包含VSSB（视觉状态空间块）和MS-SSM。在编码器对应阶段之间插入ARGFM实现逐步跨模态交互。
- 解码器：逐步上采样并融合高维特征，采用深度监督（多个解码阶段设辅助预测头）。
