## 摘要
指代遥感图像分割（RRSIS）是一项与具身感知范式相关的情境化、任务驱动的跨模态任务，要求模型将视觉空间特征与语言意图对齐以实现精确目标感知。近期研究聚焦于细化文本特征的粒度并优化图像-文本特征融合，以更好地引导目标特征表示。然而，描述粒度的不足和对语义偏移的敏感性可能导致跨模态特征融合出现瓶颈。为解决这些问题，我们提出了具有双边信息融合的图像条件实例提示网络（ICIPNet），旨在缓解跨模态特征融合的瓶颈。ICIPNet引入了图像条件实例提示（ICIP）模块，无需外部知识即可生成自适应视觉和语义表示。双边信息融合（BIF）模块增强了沿token和通道维度的特征融合。实验表明，所提出的ICIPNet优于现有RRSIS模型。

## Abstract
Referring Remote Sensing Image Segmentation (RRSIS) is a situated, task-driven cross-modal task related to the embodied perception paradigm, requiring models to align visual-spatial features with linguistic intentions for precise target perception. Recent research has focused on refining the granularity of textual features and optimizing image-text feature fusion to better guide target feature representations. However, insufficient descriptive granularity and sensitivity to semantic shifts can cause bottlenecks in cross-modal feature fusion. To address these issues, we propose the Image-Conditioned Instance Prompt Network (ICIPNet) with Bilateral Information Fusion, which is designed to alleviate bottlenecks in cross-modal feature fusion. ICIPNet introduces an Image-Conditioned Instance Prompt (ICIP) module to generate self-adaptive visual and semantic representations without external knowledge. The Bilateral Information Fusion (BIF) module enhances feature fusion along the token and channel dimensions. Experiments demonstrate that the proposed ICIPNet outperforms existing RRSIS models.

- **现存瓶颈**：现有方法（如RMSIN、MAFN、FIANet等）通常将文本特征与视觉特征在中间层直接融合，但其性能受限于：
  - 文本描述粒度不足（如高频词“物体”“区域”缺乏区分性）；

- **核心问题**：跨模态特征融合存在瓶颈，导致模型难以准确对齐视觉空间特征与语言意图。
- **论文目标**：提出一种自适应机制，利用输入图像的视觉上下文动态调整语义特征，缓解融合瓶颈。

## 2. 方法论：核心思想、关键技术细节
### 2.1 总体架构
- **输入**：RGB图像 I ∈ R^(H×W×3) + 自然语言描述 E = {ω_j}_(j=1)^N。
- **编码器**：
  - 文本：预训练BERT → 语言特征矩阵 L ∈ R^(B×N×C)；
  - 图像：预训练Swin Transformer（ST） → 分层视觉特征 V^i ∈ R^(B×P_i×C_i)，i=1,2,3,4。
- **核心模块**：
  - **ICIP（Image-Conditioned Instance Prompt）模块**：在每个ST层，生成图像条件实例提示；
  - **BIF（Bilateral Information Fusion）模块**：对视觉与语言特征进行双边融合及重建。
- **解码器**：轻量级分割解码器生成像素级掩码。

### 2.2 ICIP模块（图像条件实例提示）
- **目的**：根据输入图像的视觉上下文，自适应生成可变的语言特征，替代固定的语言分布。
- **关键步骤**：
  1. 随机初始化视觉提示矩阵 T^i ∈ R^(B×M_i×D)（M_i为提示数量）；
  2. 对视觉特征 V^i 进行线性映射得到 ˆV^i ∈ R^(B×P_i×D)；
  3. 计算相似度矩阵 A^i = tanh(ˆV^i (T^i)^⊤)，再经softmax得到注意力权重 α^i；
  4. 视觉提示更新：T_o^i = (α^i)^⊤ ˆV^i + T^i（残差聚合图像补丁特征）；
  5. 拼接视觉提示与语言特征：L_o^i = [T_o^i; L] ∈ R^(B×(M_i+N)×D)，得到包含视觉上下文和语言特征的实例提示矩阵。

### 2.3 BIF模块（双边信息融合）
- **目的**：沿token和通道维度增强跨模态特征融合，抑制注意力噪声。
- **两个子模块**：
  - **动态特征调制**：
    - 将 V^i 和 L_o^i 线性投影为 Q^i, K^i, H^i（形状 B×M_i×2D）；
    - 沿通道维度分裂为两组 {Q_1^i, K_1^i} 和 {Q_2^i, K_2^i}；
    - 引入可学习权重 λ_v（通过四个高斯初始化参数的点积计算），平衡两个子空间的贡献；
    - 计算相关性矩阵 F^i = (Q_1^i K_1^i^T)/√G_i - (λ_v/√G_i)(Q_2^i K_2^i^T)；
    - 加权输出 V_o^i = F^i H^i。
  - **多模态特征重建（MFR）**：
    - **Token混合**：沿token维度应用MLP（含GeLU），建模全局上下文关系；
    - **通道混合**：沿每个token的通道维度应用MLP，捕获跨通道依赖；
    - 残差连接得到最终重建特征 O^i。

### 2.4 训练与推理
- **损失函数**：L_total = (1-λ)L_CE + λL_Dice，λ=0.1；
- **推理**：输入图像统一resize到480×480。

## 7. 优点
- **方法创新**：提出图像条件实例提示（ICIP），使语义提示随输入图像动态变化，摆脱固定语言分布的局限，是RRSIS领域的新思路。
- **双边融合机制**：通过分裂query/key权重、引入可学习平衡系数，有效抑制注意力噪声，并通过token/通道混合重建特征，增强跨模态对齐。
- **实验设计严谨**：对比方法均重新实现以确保公平，消融实验覆盖模块、超参数、类别级分析，结论可靠。
