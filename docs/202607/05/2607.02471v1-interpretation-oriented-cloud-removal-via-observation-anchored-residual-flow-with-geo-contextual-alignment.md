## 摘要
云去除是光学遥感的关键步骤，为可靠的下游解译（如语义分割和变化检测）奠定基础。然而，现有方法往往优先追求视觉逼真度，忽略了其对后续分析任务的影响，导致语义漂移并损害下游性能。为此，我们提出地理锚定云去除（GACR）统一框架，联合确保忠实重建与鲁棒解译能力。其核心是观测锚定残差流（OAR-Flow），将云去除建模为物理驱动的残差反演过程。通过将生成轨迹锚定在含云观测而非纯噪声上，OAR-Flow实现了快速、稳定且高保真的重建。为进一步保留下游解译所需的关键语义结构，GACR集成了地理上下文先验对齐（GCPA），利用视觉基础模型（VFM）诱导的语义流形约束重建。得益于此，GACR能严格维系复杂景观的空间-语义完整性。在六个云去除数据集和十二项下游任务上的大量实验表明，GACR在取得优越重建质量的同时，持续提升了下游任务精度。代码已开源：https://github.com/wzy6055/GACR。

## Abstract
Cloud removal (CR) is essential for optical remote sensing, serving as a prerequisite for reliable downstream interpretation, such as semantic segmentation and change detection. However, existing CR approaches often prioritize visual realism while overlooking their impact on subsequent analytical tasks, leading to semantic drift and degraded downstream performance. To address this issue, we propose Geo-Anchored Cloud Removal (GACR), a unified framework that jointly ensures faithful reconstruction and robust interpretability. At its core, GACR incorporates Observation-Anchored Residual Flow (OAR-Flow), which reformulates CR as a physically grounded residual inversion process. By anchoring the generative trajectory to the cloudy observation rather than pure noise, OAR-Flow enables fast, stable, and faithful reconstruction. To further preserve semantic structures critical for downstream interpretation, GACR integrates Geo-Contextual Prior Alignment (GCPA) to constrain the reconstruction within a semantic manifold induced by a Vision Foundation Model (VFM). Consequently, GACR strictly maintains the spatial-semantic integrity of complex landscapes. Extensive experiments across six CR datasets and twelve downstream tasks demonstrate that GACR produces superior reconstruction quality while consistently improving downstream task accuracy. The code is available at https://github.com/wzy6055/GACR.

## 核心问题与整体含义
- **研究背景**：光学遥感影像是地球观测的核心数据源，用于城市监测、土地覆盖制图等下游解释任务。云层遮挡严重损害影像的表面信息与语义一致性，因此云去除（CR）成为关键预处理步骤。
- **现有问题**：当前CR方法主要分为两类：
  - 去噪型方法将云视为加性残差，在厚云下常导致结构模糊与过度平滑。
  - 生成型方法（如扩散模型）虽能合成视觉真实纹理，但缺乏显式观测锚定，易产生与真实地物不一致的“幻觉”，造成语义漂移。
- **核心矛盾**：现有方法均以像素级视觉保真度（如PSNR、SSIM）为优化目标，却忽视了下游解释任务所需的语义一致性与结构保真性，导致重建影像在分割等任务中可靠性下降。本研究旨在构建一个**面向解释的云去除框架**，同时保证重建忠实性和下游解译鲁棒性。

## 方法论
### 整体框架：GACR（Geo-Anchored Cloud Removal）
GACR融合两个核心组件：
1. **观测锚定残差流（OAR‑Flow）**——物理驱动的生成反演，确保重建过程从含云观测出发并忠实于原始地理结构。
2. **地理上下文先验对齐（GCPA）**——利用视觉基础模型（VFM）语义流形约束重建，保护地物类别与结构完整性。

### OAR‑Flow：观测锚定的残差流
- **前向过程（从干净到含云）**：构建一条连续轨迹，将干净图像 `x*` 与含云观测 `xc` 通过结构化扰动连接：
  ```
  x_t = α_t x* + β_t xc + σ_t ε
  ```
  其中 ε ~ N(0,I)，系数满足 `α_0=1, β_0=0, σ_0=0` 且 `α_T=0, β_T>0`。论文采用线性调度：`α_t=1-t, β_t=ρ t, σ_t=t`，ρ 控制观测锚定强度。
- **物理含义**：在薄云区（表面部分可观），`xc` 贡献保持低频结构；在厚云区，随机项 `ε` 提供生成灵活性。初始状态锚定于 `xc` 而非纯噪声，避免了无约束生成。
- **反向过程（推断）**：基于流匹配，学习速度场 `v_t(x) = E[α̇_t x* + β̇_t xc + σ̇_t ε | x_t=x]`。用网络 `u_t(x_t, t, xc)` 参数化该速度，通过 ODE 积分从 t=T 至 0 得到重建 `x̂*`。轨迹始终锚定于 `xc`，确保空间一致性。
- **训练损失**：速度匹配损失 `L_vel = E∥u_t(x_t) - v_t(x_t)∥²`。

### GCPA：地理上下文先验对齐
- **动机**：像素级损失不能显式保护土地覆盖语义。遥感地物具有空间连续性（如成片森林）。
- **实现**：
  - 用预训练 VFM（如 DINOv3）提取干净图像的语义特征 z*。
  - 从 OAR‑Flow 的 HDiT 骨干瓶颈层提取特征 `h_t`，经自适应投影器（ADP）映射为 z_t。
  - **地理上下文完整性损失（GCI Loss）**：计算 z* 与 z_t 之间的 patch‑wise 余弦相似度的负值：
    ```
    L_GCI = -E[ (1/N) Σ_n (⟨z*[n], z_t[n]⟩ / (∥z*[n]∥ ∥z_t[n]∥)) ]
    ```
    通过最大化相似度，将重建约束在 VFM 诱导的语义流形内。
- **总目标**：`L = L_vel + λ L_GCI`，λ 平衡重建保真与语义对齐。

### 下游解译评估
- 使用冻结的 DINOv3 骨干（与 GCPA 使用的 VFM 独立初始化）搭配轻量级任务解码器，在干净图像上训练。评估四个任务：土地覆盖分类（CLS）、建筑物提取（BLD）、语义分割（SEG）、高度估计（HE）。

## 实验设计
- **数据集与场景**：构建了包含 **6 个数据集** 的统一基准：
  - 真实云数据集：CUHKCR‑EXT‑GZ（薄云为主）、CUHKCR‑EXT‑CS（厚云较多），均有对应的土地覆盖标签，并额外标注了建筑物掩膜。
  - 合成云数据集：基于 ISPRS Potsdam 和 Vaihingen 构建了薄/厚云版本（Potsdam‑CR‑thin/thick， Vaihingen‑CR‑thin/thick），附带语义分割和高度（DSM）标注。云合成采用大气散射模型，并通过可调厚度参数控制不透明度。
- **下游任务**（共 12 项）：
  - CLS‑1、CLS‑2；BLD‑1、BLD‑2；SEG‑1∼4；HE‑1∼4。
- **对比方法**：选择了6个代表性模型：MPRNet（CNN）、Restormer（Transformer）、AST（自适应稀疏 Transformer）、MambaIR（状态空间模型）、DFCFormer（动态滤波器）、EMRDM（扩散模型）。所有基线均在同一数据划分下重新训练，以保证公平。
- **评价指标**：CR 质量用 PSNR、SSIM；分类用 Acc；建筑物提取用 IoU；分割用 mIoU；高度估计用 RMSE。

## 主要结论与发现
- GACR 在六个数据集上取得最优或次优重建质量，PSNR 最高提升 **3.3 dB**，语义分割 mIoU 提升 **3.1**。
- 下游解译精度全面提升，尤其对稠密预测任务（分割、高度估计）增益显著；特征分布更贴近云‑free 参考，缓解语义漂移。
- OAR‑Flow 通过观测锚定使收敛速度比 EMRDM 快约 **5 倍**，并减少幻构伪影。
- GCPA 显式约束使重建保持地物类别特性和空间‑语义完整性，对下游解译可靠。

## 优点
- **问题定位精准**：首次明确将云去除与下游解译耦合，超越单纯视觉质量优化。
- **创新性生成框架**：OAR‑Flow 将生成过程锚定在含云图像，物理意义清晰，既利用观测信息又保留必要生成灵活性。
- **语义先验注入**：GCPA 通过 VFM 语义流形保持地理上下文一致，形式化为可微损失，易于集成。
- **实验极其全面**：6 个数据集、12 个下游任务、多架构泛化测试、多维消融，证据坚实。
- **效率优势**：实现较快的收敛速度和较低的计算开销（p=2 时 56G FLOPs），且代码开源。

## 不足与局限
- **合成云的局限性**：四个合成数据集的云模拟基于简化散射模型，可能未涵盖真实云层的复杂空间分布、多层效应及阴影，可能限制在极端真实场景下的普适性。
- **对 VFM 的依赖**：GCPA 性能受所选 VFM 预训练质量影响；若 VFM 未能充分捕捉某些地物类别，对齐损失可能引导偏差。
- **下游任务覆盖**：实验中的下游任务主要为分类、分割、高度估计，未包括变化检测这类对时序一致性要求极高的应用，且下游模型本身基于 DINOv3 编码器，虽经异构架构测试，但仍未涉及其他主流遥感解译网络（如 Swin‑UNet 等）。
- **真实云场景下的泛化**：在 CUHKCR‑EXT 数据集上 SSIM 提升有限，且部分基线在分类任务上与端到端方法差距不大，表明 GACR 对全局分类任务的语义增益仍有提升空间。
- **超参数敏感性**：λ 和 ρ 需要根据数据集调整，缺乏自动化调参策略，可能增加实际部署成本。
