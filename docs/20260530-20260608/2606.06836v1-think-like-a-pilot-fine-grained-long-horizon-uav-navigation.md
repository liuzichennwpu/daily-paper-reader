## 摘要
语言引导的无人机智能体必须执行长时域语义指令，同时生成平滑、物理可行的连续飞行命令，然而现有的视觉语言导航（VLN）基准通常使用离散或粗略动作，现有无人机视觉-语言-动作（VLA）任务则聚焦于短时、原子操作。为填补无人机任务设置中的这一空白，我们引入了\textbf{FLIGHT}，一个用于混合无人机导航与推理任务的\textbf{细粒度长时域指令引导基准}，它结合了多阶段指令与密集的6-DoF轨迹注释，包含两个数据集划分：细粒度VLN和长时域Flow。为使无人机智能体具备对任务执行状态和任务规划的实时飞行推理能力，同时适应高频、实时精确控制，我们进一步提出了\textbf{FLIGHT VLA}，一种异步架构，它将用于任务状态推理的低频流式飞行员视觉语言模型（VLM）与用于连续控制的高频扩散动作模型解耦，并由明确的\textbf{飞行员推理}文本进行监督，这些文本总结当前飞行状态并预测下一个子目标。在闭环评估中，FLIGHT VLA在我们的FLIGHT基准上持续超越代表性VLN和VLA基线，实现了更强的多阶段完成、子目标遵循和终端控制能力。其训练的流式飞行员推理VLM进一步提升了无人机视频推理，验证了我们设计的有效性。

## Abstract
Language-guided UAV agents must execute long-horizon semantic instructions while producing smooth, physically feasible continuous flight commands, yet existing Vision-Language Navigation (VLN) benchmarks typically use discrete or coarse actions and existing UAV Vision-Language-Action (VLA) tasks focus on short, atomic maneuvers. To address this gap in UAV task settings, we introduce \textbf{FLIGHT}, a \textbf{F}ine-grained \textbf{L}ong-horizon \textbf{I}nstruction-\textbf{G}uided benchmark for \textbf{H}ybrid UAV navigation and reasoning \textbf{T}asks, which combines multi-stage instructions with dense 6-DoF trajectory annotations across two dataset splits: Fine-grained VLN and Long-horizon Flow. To endow the UAV agent with the capability of real-time in-flight reasoning over task execution status and mission planning, while simultaneously accommodating high-frequency, real-time precise control, we further propose \textbf{FLIGHT VLA}, an asynchronous architecture that decouples a low-frequency Streaming Pilot Vision-Language Model (VLM) for task-state reasoning from a high-frequency diffusion action model for continuous control, supervised by explicit \textbf{Pilot Reasoning} texts that summarize the current flight state and anticipate the next subgoal. In closed-loop evaluation, FLIGHT VLA consistently surpasses representative VLN and VLA baselines on our FLIGHT benchmarks, achieving stronger multi-stage completion, subgoal adherence, and terminal control. Its trained Streaming Pilot Reasoning VLM further improves UAV video reasoning, validating the effectiveness of our design.

## 2. 方法论

### 核心思想
- **异步快–慢双系统架构**：将系统解耦为两个以不同时间尺度运行的模块：
  - **慢模块（低频流式飞行员VLM）**：负责在线视频理解、任务阶段识别和高层规划，输出语义特征与推理文本（约0.5~1 Hz）。
  - **快模块（高频扩散动作模型）**：基于实时视觉、状态和最新语义特征生成连续动作序列（约10~30 Hz）。

### 关键技术细节
- **Streaming Pilot VLM**（式4、式5）  
  - 输入：任务指令 \(I\)、近期视觉观测滑窗 \(V_{[\tau-W_i:\tau]}\)、无人机状态 \(S_{[\tau-W_i:\tau]}\)、历史推理记忆 \(M_{[\tau-W_M:\tau]}\)。  
  - 输出：飞行员推理文本 \(M_\tau\)（总结当前状态和预测下一步动作）及语义特征 \(z_\tau\)（输入/输出 token 的隐状态）。  
  - 基于 StreamingVLM（Xu et al., 2025）实现，采用重叠分块全注意力训练。

- **Diffusion Action Model**（式6–8）  
  - 独立视觉编码器（Vision Transformer）实时编码当前帧 \(V_t\) 得到 \(f_t\)；相对姿态编码 \(q_t\) 表示当前无人机在 VLM 推理帧坐标下的相对位姿。  
  - 条件特征 \(c_t = [f_t; q_t; z_{\tau(t)}]\)（\(\tau(t) < t\) 表示最新可用的 VLM 特征）。  
  - 基于 DiT（Diffusion Transformer）的流匹配目标，生成未来 \(H\) 步的连续动作序列（含位移 \(\Delta x,\Delta y,\Delta z\) 和姿态角变化）。

- **训练策略**  
  - 两阶段联合训练：先联合优化 VLM 和动作模型（损失权重 \(\mathcal{L} = 0.1\mathcal{L}_{vlm} + \mathcal{L}_{act}\)），再冻结 VLM 继续微调动作模型。  
  - **异步延迟模拟**：在训练时人为引入不同时间偏移的 VLM 特征（如1秒、3秒延迟），使动作模型学会适应推理延迟。

## 3. 实验设计

- **数据集**：FLIGHT 基准包含两个子集：
  - **Fine-grained VLN**：6,689条轨迹，平均长度154.5 m，每百米含6.23个动词、12.26个名词、6.55个形容词，连续动作采样率10 Hz。
  - **Long-horizon Flow**：4,098条轨迹，包含8种原子动作类别，平均3.37个动作实例，轨迹平均长度32.8 m。
  - 环境：基于 Unrealzoo 构建的城市场景、工业场景和乡村场景。
- **基准方法**：
  - **VLA基线**：OpenVLA-UAV、Memory VLA（针对Long-horizon Flow任务）。
  - **VLN基线**：CMA+LAG、NaVid（针对Fine-grained VLN任务）。
  - **VLM推理任务**：对比 Gemini-3-flash、Qwen 3.6 plus、Qwen 2.5 VL 3B。
- **评估指标**：
  - **Long-horizon Flow**：Success Rate (SR)、Stage Success Rate (SSR)、Normalized DTW (NDTW)。
  - **Fine-grained VLN**：SR、Oracle Success Rate (OSR)、Navigation Error (NE)、Instruction Adherence Success Rate (IASR)。
  - **VLM推理**：GPT-5评估语义一致性准确性（State Acc. 和 Action Acc.）。

## 6. 主要结论与发现

- FLIGHT VLA 在 **Long-horizon Flow** 上显著优于 OpenVLA-UAV 和 Memory VLA（SR: 59.0% vs 10.5%/18.5%；SSR: 78.97% vs 30.87%/38.69%）。
- 在 **Fine-grained VLN** 上，FLIGHT VLA 在 IASR（指令遵循成功率）上达到11.0%，远高于 CMA+LAG（4.5%）和 NaVid（5.0%），且 SR/OSR 也最高。
- 训练的 **Streaming Pilot Reasoning VLM**（3B参数）在状态推理准确性达64.2%、动作推理准确性达68.1%，远超其他通用VLM（如Gemini-3-flash的25.8%/39.1%）。
- 验证了异步快慢架构和**飞行员推理**文本的设计有效，能解决长时域任务中的语义漂移、子目标遗忘和实时控制冲突问题。

## 7. 优点

- **创新性**：首次将流式VLM与扩散动作模型以异步方式结合，解决了无人机长时域导航中语义推理与高频控制的矛盾。
- **数据质量**：FLIGHT数据集由人类专家收集，包含密集的6-DoF轨迹和细粒度语义标注（动作、地标、方向等），并引入“飞行员推理”文本作为显式中间监督。
- **鲁棒性设计**：训练时模拟不同VLM推理延迟，使动作模型适应真实异步场景，提升闭环稳定性。
- **全面评估**：从离散指标（SR）到细粒度子目标遵循（IASR、SSR）再到VLM推理准确性，多维度考察模型能力。
- **开放贡献**：代码、数据集、模型均开源（GitHub、HuggingFace）。
