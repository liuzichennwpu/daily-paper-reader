## 摘要
视觉语言模型（VLM）已成为连续环境下视觉语言导航（VLN-CE）的常见基础。然而，大多数基于VLM的方法将导航视为低层动作预测，这种接口存在歧义、局限于短视运动基元，且因重复查询VLM而效率低下。我们提出Goal2Pixel，一种纯像素范式，将VLN-CE重构为可导航像素锚定。Goal2Pixel不预测动作，而是将图像平面作为VLM推理与机器人运动之间的统一空间接口：模型预测智能体的一个可见可导航像素，该像素被反投影为3D航点用于前向导航。对于非前向动作，我们在图像平面上附加辅助指示区域，其中左/右/底部区域分别解释为左转、右转和停止。为实现长程导航，我们提出了一种可见性感知的关键帧记忆，用于紧凑且信息丰富的历史表示。为适应预训练VLM进行可导航像素锚定，我们引入了语义嵌入和坐标感知辅助损失。Goal2Pixel实现了具有竞争力的最先进性能，同时所需的VLM推理调用少于先前方法。在R2R-CE Val-Unseen上，它仅需每集7.75次VLM调用即可达到54.1%的SR和52.5%的SPL，比直接动作预测所需的46.62次（SR为32.9%）减少了6倍。在RxR-CE上也观察到相同趋势。项目页面：https://baobao0926.github.io/Goal2Pixel/。

## Abstract
Vision-language models (VLMs) have become a common foundation for vision-and-language navigation in continuous environments (VLN-CE). Yet most VLM-based methods cast navigation as low-level action prediction, an interface that is ambiguous, tied to short-horizon motion primitives, and inefficient due to repeated VLM querying. We propose Goal2Pixel, a pure pixel-based paradigm that reformulates VLN-CE as navigable pixel grounding. Rather than predicting actions, Goal2Pixel uses the image plane as a unified spatial interface between VLM reasoning and robot motion: the model predicts a visible navigable pixel to the agent, which is back-projected into a 3D waypoint for forward navigation. For non-forward actions, we append auxiliary directive regions to the image plane, where the left/right/bottom regions are interpreted as turning left, turning right, and stopping, respectively. To enable long-horizon navigation, we propose a visibility-aware keyframe memory for compact and informative history representation. To adapt pretrained VLMs to navigable pixel grounding, we introduce semantic embeddings and coordinate-aware auxiliary losses. Goal2Pixel achieves competitive state-of-the-art performance while requiring fewer VLM inference calls than prior methods. On R2R-CE Val-Unseen it achieves 54.1% SR and 52.5% SPL with just 7.75 VLM calls per episode, 6x fewer than the 46.62 required by direct action prediction at 32.9% SR. The same trend holds on RxR-CE.Project Page: https://baobao0926.github.io/Goal2Pixel/.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题背景**：视觉语言导航（VLN-CE）要求智能体在连续环境中根据自然语言指令执行导航。当前主流方法使用视觉语言模型（VLM）预测低级动作（如前进25cm、左转15°等），但存在三大根本局限：
  - **接口歧义**：大量不同动作序列可到达相同目标，使监督信号模糊。
  - **短视决策**：优化下一个短距离移动而非长程空间推理。
  - **高推理成本**：每个动作仅推进数厘米/度，导致每集需调用VLM数十次。
- **整体含义**：瓶颈不在于VLM能力，而在于其推理与运动执行的接口。作者提出纯像素范式**Goal2Pixel**，将导航重构为图像空间中的可导航像素定位，将图像平面作为统一的接口，从而解耦高层推理与低层执行、减少调用次数、提升长程效率。

## 2. 方法论
### 核心思想
- 将VLN-CE转化为**可导航像素定位**：VLM在当前第一人称RGB图像上预测一个可见可导航像素，通过相机几何反投影为3D航点，由轻量级局部规划器转换为连续低层动作。
- 对于非前进动作（左转、右转、停止），在图像左、右、底侧附加**辅助指示区域**，区域内像素分别解释为对应动作。所有动作决策统一在像素预测接口中。

### 关键技术细节
1. **数据采集**：
   - 从R2R-CE和RxR-CE的训练集（MP3D场景）构建2.64M样本，每个样本为 (指令, 当前图像, 历史图像, 目标像素) 四元组。
   - **GT像素构造**：投影沿Oracle轨迹最远的可见未来航点，通过投射-重投影一致性检验（距离<0.6m）确保可见性。终点附近1.0m内→底部辅助区域（停止）；无可视航点→左/右辅助区域（通过后续航点平均方向决定）。
2. **历史记忆ViKeyMem**：
   - 基于可见性变化选择关键帧，仅当候选帧不被上一个关键帧覆盖、且至少一个后续航点可见、且至少两个后续航点位于45°前向视野内时，才作为新关键帧加入。
   - 在保留的关键帧上叠加蓝色轨迹点，显式连接远近观测。
   - 典型每100时间步仅保留4~5个关键帧，显著减少冗余。
3. **视觉语义嵌入**：
   - 为辅助区域像素添加可学习的**指示嵌入**，为历史关键帧中的轨迹叠加部分添加**轨迹嵌入**，帮助VLM区分这些特殊视觉模式。
4. **训练目标**：
   - 主损失：标准token级交叉熵损失 L_CE（预测坐标字符串 "XXX, YYY"）。
   - 辅助损失（坐标感知）：
     - **数值损失 L_num**：预测与GT像素坐标归一化后的L1距离。
     - **角度损失 L_ang**：预测与GT像素从底部中心锚点到像素的航向角的余弦差异。
   - 总损失：L = L_CE + λ_num·L_num + λ_ang·L_ang（权重分别为0.3和0.03）。

### 算法流程（文字说明）
1. **每次决策时**：将指令、当前图像（已拼接辅助区域）、ViKeyMem选择的历史关键帧输入VLM。
2. **VLM输出**：一个坐标字符串，如 "123,456"。
3. **坐标判定**：
   - 若像素落在常规RGB区域 → 利用深度反投影为3D航点，调用局部规划器执行最多t个低层动作（实验设置t=5）。
   - 若落在左/右/底部辅助区域 → 分别执行左转/右转/停止。
4. **重复**直到输出停止或达到最大步数。

## 6. 主要结论与发现
- Goal2Pixel（纯像素范式）在R2R-CE Val-Unseen上达到54.1% SR、52.5% SPL，在RxR-CE Val-Unseen上达到48.1% SR、44.7% SPL，相比使用外部数据的JanusVLN（52.8% SR/49.2% SPL）在SPL和nDTW上更优，且调用次数大幅减少（7.75次 vs 数十次）。
- 相比直接动作预测（One Action），纯Pixel提升SR 21.2个百分点，调用次数减少约6倍。
- 相比混合Action-Pixel序列方法（DualVLN风格），Pixel提升SR 10.4个百分点（R2R-CE）。
- ViKeyMem在长程复杂指令（RxR）上优于均匀和历史固定间隔采样，且降低推理时间和训练成本。
- 坐标感知损失（数值+角度）和语义嵌入均带来稳定增益。
- 低层执行步数t=5提供最佳效率-性能平衡。

## 7. 优点
1. **创新性接口**：首次将VLN-CE完全重构为纯像素定位任务，统一所有动作决策（前进/转向/停止）于同一坐标空间，消除动作歧义。
2. **高效推理**：像素预测使得单个VLM调用可引导多个低层动作，大幅减少查询次数（6x），同时提升导航质量。
3. **紧凑历史记忆ViKeyMem**：基于可见性变化的关键帧选择，冗余度极低、计算效率高，且无需额外架构或记忆模型。
4. **轻量级适配**：仅引入可学习语义嵌入和两个辅助损失，即可有效微调预训练VLM，不改变骨干网络。
5. **跨平台潜力**：像素输出解耦高层推理与机器人具体动作空间，在真实Mecanum轮式机器人上成功部署，展示跨实体可行性。

## 8. 不足与局限
- **深度依赖**：需要可靠的深度传感器或估计才能将2D像素反投影为3D航点，限制了在没有深度信息的场景中的应用。
- **场景局限**：仅在室内VLN-CE基准（MP3D）上训练和评估，未验证在户外或更开放环境中的鲁棒性。
- **监督不平衡**：GT像素分布高度集中于图像下部常见模式，可能对罕见像素位置缺乏泛化能力。
- **细粒度损失**：ViKeyMem可能遗漏中间关键细节，且难以编码短期运动记忆（如最近一次转向），有时需依赖手写防振荡回退策略。
- **真实世界验证不足**：仅16次定性实验，未报告定量成功率、路径长度等指标，且受限于8GB显存，历史帧数减少。
- **超参数敏感**：低层执行步数t需要手动调节，设置不当（太大或太小）会降低性能。
